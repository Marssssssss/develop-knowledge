# YOLO 检测头(Anchor-based Detection Head)

## 简介

YOLO 把检测变成一个**单阶段的回归问题**:在降采样后的特征图上,每个格子直接回归若干框的中心、
尺寸、objectness 与类别概率。它的"检测头"是整套设计里最值得单独研究的部分 —— 因为几乎所有
后续的单阶段检测器(SSD、RetinaNet、YOLOv5/v8 …)都沿用了这套头部约定。

本目录用**纯标准库**实现并验证检测头本身:锚框解码、多尺度网格、正/负/**忽略**三态样本分配、
softmax 与独立 logistic 的语义差别、k-means 锚框聚类、以及损失里"忽略规则"的必要性。
不加载任何权重与数据集 —— 头部是纯粹的坐标变换与集合运算,可以逐条断言。

```
python/  yolo_head.py(头部/分配/分类器/k-means)  yolo_head_check.py(自检 45 条,A~F 六段)
go/      yolo_head.go(头部与分配)  anchors.go(k-means/手工基线)  main.go(自检)
```

> Go 侧拆 3 个文件是为守住「单文件 ≤ 300 行」的仓库硬约束,属同一 `main` 包,用 `go run .` 一次编译。

## 原理详解

### 1. 头部输出布局

若某尺度上的特征图是 `S×S`,每格配 `B` 个锚框,则头部张量是 `S×S×B×(4+1+C)`:
4 个框偏移 + 1 个 objectness + C 个类别分数。COCO 下 C=80,`B=3`,
13×13 层的张量就是 **13×13×3×85 = 43095** 个数(自检 B 段)。
注意这 85 维里绝大多数是分类分数,真正与"框在哪"有关的只有 4 维 —— 这也是单阶段检测器
分类与定位耦合、训练时正负样本极度不均的根源。

### 2. 中心用 sigmoid:把预测绑在格子里

论文写的是 `bx = σ(tx) + cx`、`by = σ(ty) + cy`、`bw = pw · e^tw`、`bh = ph · e^th`。

`(cx, cy)` 是格子坐标。**σ 把偏移压进 (0,1)**,于是无论 `tx` 多大,预测中心都落在**该格内部**
(自检 A 段用 tx = ±20 验证过)。收益有两点:训练稳定(偏移不会跑出格子,无需额外归一化);
尺度无关(同一个 `tx` 在不同尺度层上都表示"格内相对位置")。

代价是**量化误差**:中心只能落在格内,最大误差是半个 stride。输入 416 时三个尺度的
stride 是 32 / 16 / 8,对应最大误差 **16 / 8 / 4 px**(自检 B 段)。
真实中心 (191, 245) 在 13×13 层上会被量化到格 (5,7) 的中心 (176, 240),误差 (15, 5) ——
**一个 16px 的误差预算,对小目标等于灾难**。这正是必须做多尺度预测的原因:不是"顺便涨点",
而是细目标在粗层上根本无法定位。

### 3. 尺寸用指数缩放锚框

`bw = pw · e^tw` 里 `pw` 是锚框宽度。取指数而不是线性,是因为框的尺寸是**乘性**的量:`tw = 0` 时
`bw = pw`;`tw = 1` 时宽度放大 **e ≈ 2.718** 倍(自检里 116 → 315.320692),也让"把框放大一点"在不同尺度上含义一致。

编码是解码的逆运算:`tw = ln(bw / pw)`,中心部分 `tx = logit(cx/stride - gx)`。
自检里 encode → decode 往返误差 < 1e-9。

### 4. 多尺度:三个尺度的预测数

13×13 + 26×26 + 52×52 三层的预测框数为 `3·(13² + 26² + 52²)` = 3·3549 = **10647**(自检 B 段);
只保留 13×13 一层就只有 507 个,**相差 21 倍**。粗层感受野大、负责大目标,细层负责小目标,
层间还通过上采样 + 通道拼接把粗层语义传下去。

### 5. 正 / 负 / 忽略:三态分配

论文的规则是两句:

1. 与 ground truth 的 **IoU 最大**的锚框负责该目标(→ 正样本);
2. **非最优但 IoU 超过 0.5** 的锚框**被忽略** —— 既不奖励也不惩罚。

自检 C 段用一个具体例子把三态钉住:GT 形状 (100,100),锚框 (100,100) / (80,90) / (50,200),
形状 IoU 分别是 1.0 / 0.72 / 0.3333,于是负责 = 0、忽略 = {1}、负样本 = {2}。

判据是 **strictly > 0.5**:形状 (10,10) 与 (10,20) 的 IoU 恰为 0.5,**不**进入忽略集。
写实现时用 `>=` 就会在边界上分错样本(自检专门有这一条)。

### 6. 为什么丢弃 softmax:重叠标签

softmax 的定义蕴含"类别互斥"(Σp = 1),但真实数据集的标签是**重叠**的 ——
一张图里的人既属于 Person 也属于 Woman。YOLOv3 因此换成**每个类各自一个 logistic 分类器**,
类之间不再竞争。

自检 D 段用同一组 logits `[8, 6]` 把差别量化出来:

| 口径 | 输出 | 能否同时为真 |
|---|---|---|
| softmax | (0.880797, 0.119203),和为 1 | 不能:第二名被压到 0.119 |
| 独立 logistic | (0.999665, 0.997527),各自独立 | 能:两类都接近 1 |

用交叉熵衡量差别更直观:同一组 logits、同一个目标类 1,
softmax 交叉熵是 **2.126928**(把第二名判成错),而独立 logistic 的 BCE 只有 **0.002811**。

### 7. k-means 选锚框:d = 1 − IOU

锚框尺寸不该凭手感定。YOLO9000 用 **k-means** 在训练集真实框上聚类,距离定义为

```
d(box, centroid) = 1 - IOU
```

**为什么不用欧氏距离**:同样差 10 个像素,对大框只是噪声、对小框是灾难;欧氏距离会把两者
等同看待,聚类结果偏向大框。用 `1 − IoU` 则天然是"形状相似度"。

论文报告该数据集上 k=5 得到 avg IOU **61.0**,与 Faster R-CNN 手工选的 9 个锚框(60.9)相当 ——
即"5 个聚类锚框 ≈ 9 个手工锚框"。**本 demo 不下载 VOC 2007,故不复现这两个数值**;
改为在合成数据上复现这条结论的形式(见下)。

自检 E 段:造三个已知尺寸簇 (40,40) / (120,60) / (200,240),每簇 100 个框、±12% 抖动,

| 锚框设置 | avg IOU |
|---|---|
| k = 1 | 0.3021 |
| k = 2 | 0.6181 |
| k = 3 | 0.8889 |
| k = 5 | 0.9067 |
| k = 9 | 0.9308 |
| **oracle**(直接用三个真尺寸当锚框) | 0.8879 |
| RPN 手工 9 个(3 尺度 × 3 宽高比) | **0.1354** |

三点值得注意:①avg IOU 随 k **单调不减**(锚框越多越能覆盖真实尺寸),这是 k-means 目标函数的性质;
②k = 3 **略微超过 oracle 0.8879** —— 质心是样本均值,比"真值尺寸"更贴合这批抖动样本,
所谓 oracle 只是另一个锚框集合,并非上界;③手工锚框惨败(0.1354),因为它的最小锚框也有 90.5px,
而分布里有 40px 的簇 —— **锚框必须按数据集分布定**,这正是论文主张聚类的实证依据。

### 8. 损失与"忽略"的必要性

objectness 用二元交叉熵 `-[y·ln p + (1-y)·ln(1-p)]`,类别用**逐类独立**的 BCE(与 §6 呼应)。
自检 F 段量化了忽略规则的份量:同一次预测,忽略那个"自信但 IoU 没到最优"的锚框时损失是
**0.210721**;把它当负样本惩罚则暴涨到 **27.8417**(放大 132 倍)—— 因为 `p=0` 而 `y=1` 时
BCE 里出现 `-ln(1e-12) ≈ 27.63`。一次这样的样本就足以主导整个 batch 的梯度,
所以忽略规则不是精细化操作,而是**数值稳定性**要求。

## 对比

| 维度 | YOLO 头(本 demo) | 两阶段 Faster R-CNN | Anchor-free(FCOS/CenterNet) |
|---|---|---|---|
| 阶段 | 单阶段稠密回归 | RPN 提候选 + 二阶段精修 | 单阶段逐点回归 |
| 先验 | 锚框(需按数据集聚类) | 锚框(手工) | 无锚框 |
| 正样本定义 | IoU 最大 + 忽略阈值 | IoU 阈值区间 | 落入中心区域即正 |
| 类别耦合 | 每格独立多标签 logistic | softmax(单一类别) | 多标签 |

与同类目 042/043/044(Canny、Harris、IoU-NMS)的关系:NMS 是**后处理**,本 demo 是**前向头**
与训练期分配;两者共同构成单阶段检测器的两端。

## 性能与边界

- 头部算力只与输出张量成正比:三尺度合计 **10647 × 85 ≈ 9.05e5** 个数,**成本主要在主干与后处理**;
- 分配是 `O(GT 数 × 网格数 × 锚框数)`;Darknet 的忽略集需在全部位置×锚框上算 IoU,
  在 10647 个预测与数十个 GT 下开销可观,也是后续版本改用"跨网格候选"等工程优化的原因;
- 边界:**极小目标**受量化误差限制(52×52 层仍有 4px),再小需更高分辨率输入或专门的头;
  **极端长宽比**超出锚框覆盖时 `e^tw` 需回归很大的 `tw`,训练不稳定;
  **拥挤场景**下多目标中心落在同一格时,只能靠每格 3 个锚框与相邻格共同覆盖。

## 注意事项与常见坑

1. **σ 在 float64 下会精确饱和**:σ(36) 仍 < 1,但 σ(37) 就是**精确的 1.0**
   (`1 + e^-37` 已落在 1.0 的舍入区间内),此时中心落在格边界,是退化解。负向不对称:
   σ(-37) = 8.53e-17 仍是可表示的数,要到指数下溢(x < -745)才归零。
   **推论:不要假设 σ 输出严格小于 1,也不要假设正负两侧饱和点对称。**
2. **忽略规则的作用对象容易搞混**:论文与 Darknet 里这条规则比较的是**网络预测框**与 GT;
   本 demo 没有权重,退化为比较**锚框形状**。判据形式相同(> 0.5)但比较对象不同,
   代码注释与本节都做了标注。
3. **0.5 是严格大于**:IoU 恰为 0.5 时**不忽略**。用 `>=` 会在边界分错。
4. **锚框必须按数据集分布聚类**:同一批数据上手工锚框的 avg IOU 可以只有聚类锚框的 1/7
   (0.1354 vs 0.9067),别直接用别人数据集上的锚框尺寸。
5. **别把 softmax 和 sigmoid 的输出混用**:同一个 logits 下两者语义完全不同
   (0.119 vs 0.998),换分类器时损失的实现必须同步换。
6. **每格 3 个锚框 ≠ 3 个正样本**:只有 IoU 最大的那 1 个负责,其余要么忽略要么为负。
   正负比极端失衡是单阶段检测器的固有特征,需要 focal loss 一类手段处理。
7. **`tw` / `th` 是相对锚框的对数比**,不是绝对尺寸;换锚框尺寸就必须重算编码目标。
