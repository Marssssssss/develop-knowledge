# TRPO:信赖域约束的单调改进 + 共轭梯度实用化

> TRPO 的理论出发点只有一句话:**最大化一个"局部可信"的代理目标,
> 真目标就不会倒退**。为了让这句话在大规模策略上落地,论文做了一连串
> 工程取舍(惩罚→硬约束、max-KL→平均 KL、二阶解→CG+线搜索)——
> PPO 是这条简化路线的终点。

## 1. 单调改进的数学骨架(Schulman et al. 2015)

- **Kakade & Langford 恒等式**:η(π̃) = η(π) + E_{π̃}[ΣγᵗA_π]——
  新策略的真实回报,等于旧值 + 沿**新策略**轨迹累积的优势;
- 把轨迹分布换成旧策略的,得到代理 L_π(π̃)(用比率 × 优势的期望);
- **Theorem 1**:`η(π_new) ≥ L_πold(π_new) − 4εγ/(1−γ)² · α²`,
  α = 两策略的最大总变差距离——惩罚项为代理的乐观偏差兜底;
- **MM 算法视角**:代理函数在 π_old 处与 η 相等且处处下界,
  每步最大化代理 → η 单调不减(与 EM 同族)。

## 2. 从理论到实践的三个替换

| 理论版 | 实践版 | 原因(论文原文口径) |
| --- | --- | --- |
| 惩罚项 C·KL | **硬约束 D_KL ≤ δ** | "理论推荐的惩罚系数会使步长非常小";惩罚系数难以稳健选取 |
| max-KL | **平均 KL**(样本均值) | max-KL 难以数值优化与估计 |
| 直接二阶优化 | **CG + 回溯线搜索** | "代价只略高于计算梯度本身";免存/求逆 FIM |

## 3. 信赖域步的三件套

```text
1) CG 解 F·s = g(F = KL 的解析 Hessian,即 Fisher 信息矩阵)
2) 步长 β = sqrt(2δ/(sᵀAs)) —— 二次近似 ½(βs)ᵀF(βs) = ½β²sᵀAs = δ 打满预算
3) 回溯线搜索 θ_j = θ_old + α^j·βs:
   接受条件 = 代理改善 AND 真 KL ≤ δ(两者对 θ 都是非线性的,
   二阶近似只在信赖域内可信)
```

- FIM 用 **KL 的解析 Hessian** 而不是梯度协方差(论文明言);
- sᵀAs 是 CG 的**中间量**,零额外成本;
- 全部候选失败 → 原地不动:MM 结构保证"最坏不改进,绝不倒退"。

## 4. 与 PPO 的对照

TRPO 保信赖域的手段是"KL 硬约束 + 二阶方向 + 线搜索";
PPO 把同一件事换成**比率裁剪**(一阶近似,无二阶求解)——
更简单、 minibatch 化更自然,但信赖域从"解出来的"变成"裁出来的"。
见本目录 [PPO/](../PPO/)。
