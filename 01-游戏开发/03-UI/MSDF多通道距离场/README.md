# MSDF 多通道距离场（Multi-channel SDF）

## 简介

单通道 SDF 能用 64² 纹理渲染出任意放大倍率的平滑字形，但**尖角会被抹圆**——因为重建依赖插值，而插值只在"变化率大致恒定"的地方成立，角点附近恰恰不恒定。**MSDF**（Multi-channel Signed Distance Field）把形状分解成若干**平滑**子形状，各生成一张距离场塞进 RGB 三个通道，重建时取三通道的**中位数**，尖角由"两条直线相交"得到，从而在同样低的分辨率下保住锐角。

- **median-of-three**：`d = median(s.r, s.g, s.b) - 0.5`，三个维度可互换
- **角点象限编码**：一个角被分成四个象限，每个象限是一个 3 维 0/1 向量，median 决定内外
- **伪距离（pseudo-distance）**：沿边所在**直线**量取、叉积定符号，抹掉"到最近点"距离的非线性脊线
- **边着色**：颜色按**边**分配，每条边共四个颜色（内外各两个，对应前半段/后半段）
- **fwidth 抗锯齿**：`w = clamp(d/fwidth(d) + 0.5, 0, 1)`

出处：Viktor Chlumský 硕士论文《Shape Decomposition for Multi-channel Distance Fields》（捷克技术大学，2015），工程实现即同作者的 `msdfgen`；Unity TextMeshPro 的默认字体图集就是 MSDF。

## 原理详解

### 1. 为什么单通道 SDF 保不住尖角（§1.1.3）

取凸直角 `{x > cx, y > cy}`，真实有符号距离是分段的：

```
dx>0,dy>0 → min(dx,dy)      线性
dx<0,dy>0 → dx              线性
dx>0,dy<0 → dy              线性
dx<0,dy<0 → −√(dx²+dy²)     ← 非线性！
```

最后一支的等值线是**圆弧**，双线性插值只能给出四边形网格上的分片线性面，于是角点被"抹"成圆角或缺口。论文原话："the corners cannot be reconstructed correctly, and will instead look rounded or chipped"。

### 2. median-of-three（§3.2.2，式 3.13）

论文用程序穷举后得到**最小维度 n = 3**，并给出最直观的模型：

```
‖A‖ := median(a1, a2, a3)
```

一个角被两条边分成四个象限，每个象限是一个 3 维 0/1 向量（Figure 3.7）：

| 角类型 | 四象限向量 | median 后的内外 |
| --- | --- | --- |
| 凸角 | (1,1,0) (1,0,0) (0,1,0) (0,0,0) | 恰 **1** 个象限为内 |
| 凹角 | (1,1,1) (1,0,1) (1,1,0) (1,0,0) | 恰 **3** 个象限为内 |

median 本质是**多数表决**：凸角要"两个通道都说在内"，凹角要"至少两个通道说在内"——而 min（n≤2）只能表达交集、表达不了并集，这正是 n 至少为 3 的直觉来源。本 demo 用穷举复现了这个结论：限定每个通道必须是**平滑形状**（在角点处要么不经过、要么是一条直线，即四象限上为 0000/1111/相邻两象限为 1 共 6 种模式），则凸角 n=2 可行、**凹角 n=3 才可行** → 两种角都要能表达 ⇒ **n = 3**，与论文一致。

### 3. 伪距离（§2.5）

真实"点到线段最近点"的距离在边的端点外会切换参考点，产生脊线；伪距离改为**沿边所在直线**量取并用叉积定符号：

```
d(P, AB) = ((B−A) × (P−A)) / |B−A|      其中 (x1,y1) × (x2,y2) := x1·y2 − y1·x2
```

- 投影落在边内时，伪距离与真实距离**相等**；
- 投影落到延长线上时二者分离（实测：边 (0,0)→(1,0)、点 (5,3)，伪距离 3.000，真实距离 5.000）；
- 关键是伪距离**沿边方向严格线性** ⇒ 双线性插值精确。

### 4. 重建与抗锯齿（§5.1，论文给出的完整 GLSL）

```glsl
float median(float a, float b, float c) {
    return max(min(a, b), min(max(a, b), c));   // 只用 min/max，无分支
}
void main() {
    vec3 s = texture2D(sdf, P).rgb;
    float d = median(s.r, s.g, s.b) - 0.5;      // 0.5 是编码里的"轮廓"
    float w = clamp(d/fwidth(d) + 0.5, 0.0, 1.0);
    gl_FragColor = mix(outsideColor, insideColor, w);
}
```

阈值区间 ⟨−t, t⟩ 的宽度应约等于**目标位图里的一个像素**；3D 场景里距离场的屏幕尺度不恒定，所以用 `fwidth` 逐像素求。

### 5. 定量实验（本 demo [6]，角点刻意不对齐网格）

域 [−4,4]²，输出 65²，比对重建结果与真值：

| 距离场网格 | SDF 错像素 | SDF 最大偏差 | MSDF 错像素 |
| --- | --- | --- | --- |
| 5² | **57** | 2.085 | **0** |
| 9² | 17 | 1.085 | 0 |
| 17² | 1 | 0.085 | 0 |
| 33² | 1 | 0.085 | 0 |

MSDF 在**任意**网格分辨率下都是 0 误差：它的 R/G 两通道本身是线性函数（`y−cy` 与 `x−cx`），双线性插值对线性函数是**精确**的，尖角由两条精确直线相交得到。SDF 只能靠提高分辨率去逼近。

## 对比 / 选型

| 方案 | 尖角 | 纹理内存 | 重建成本 | 适用 |
| --- | --- | --- | --- | --- |
| 位图字体 | 好 | 大（需多尺寸） | 1 次采样 | 固定字号 |
| 单通道 SDF | **圆化** | 小 | 1 次采样 + 阈值 | 圆润字体、图标 |
| **MSDF（3 通道）** | 几乎完美 | SDF 的 3 倍 | 1 次采样 + median(3) | 有锐角的正文/标题 |
| MSDF（4 通道，含 alpha） | 同上 | 4 倍 | median(4) 需两次 median3 | 论文 §7.1 的展望方向 |
| 矢量轮廓（GLyphy 等） | 完美 | 极小 | 高（逐像素求贝塞尔） | 超大字号 |

## 关键代码片段

```python
def median3(a, b, c):
    """§5.1.4 的 GLSL 写法：只用 min/max，无分支。"""
    return max(min(a, b), min(max(a, b), c))

def corner_msdf(x, y, floor_value=-8.0):
    """凸直角的 MSDF：两通道各是一条直线（半平面），第三通道恒为外。"""
    return (y - CORNER_Y, x - CORNER_X, floor_value)
    # median(y-cy, x-cx, -8) 恰好等价于 min(dx, dy) —— 尖角由两直线相交得到
```

## 性能与边界

- 重建只多出 2 次 `min`/`max`，是**无分支**的，GPU 上几乎免费；代价是纹理内存 ×3。
- 8-bit 量化下每通道只有 256 级，距离范围（spread）设得越大、每级代表的距离越粗；实践中用 `pxRange` 显式控制。
- MSDF 对**三通道交叉点**（一个像素里三条以上轮廓交汇）无力：论文 §7.1 把它列为未来工作，实际字形里可通过加 padding / 提高分辨率规避。
- 距离场的重建阈值必须与**屏幕上的实际缩放**挂钩（用 `fwidth`），否则放大后边缘过渡带宽度会失真。

## 注意事项与常见坑

1. **median 不能写成 "取中值排序" 的分支版本**——shader 里用 `max(min(a,b), min(max(a,b),c))` 是 3 条指令无分支，且对三通道顺序不敏感。
2. **角点若恰好落在纹素中心，SDF 看起来"没问题"**——一旦角点落在纹素之间（真实字形几乎总是如此），误差立刻暴露。做对比实验时一定要让角点**不对齐网格**。
3. **第三通道不是"备用通道"**：凸角场景下它恒为外（本 demo 的 `floor_value`），凹角场景下它承担"并集"语义，缺了它凹角会缺一块。
4. **边着色要分前后半段**（§4.3.1：每条边四个颜色），因为一条边的两端可能属于不同的角、需要不同的通道组合。
5. **不要用真实"点到线段"距离生成 MSDF**：端点外的脊线会破坏可插值性，要用伪距离。
6. **MSDF 只解决锐角，不解决所有细节**：极细笔画、复杂衬线在过低分辨率下依然会糊，需要按字号分档出图集。
