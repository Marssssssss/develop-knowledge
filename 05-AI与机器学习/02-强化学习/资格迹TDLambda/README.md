# 资格迹与 TD(λ)

## 简介

资格迹(eligibility trace)是 TD 学习里的一个**短期记忆**变量:它记住"哪些状态最近被访问过、有多近",
让每个时刻的 TD 误差都能按比例回传给这些状态。TD(λ) 就是把 $n$ 步回报按几何权重 $λ$ 加权求和,
在 **TD(0)** 与**蒙特卡洛**之间做连续插值。

关键概念:

| 概念 | 一句话解释 |
| --- | --- |
| $n$ 步回报 $R_t^{(n)}$ | 走 $n$ 步真实奖励 + 第 $n$ 步用 $V$ 自举 |
| $λ$-回报 $R_t^λ$ | $(1−λ)\sum_{n\ge1}λ^{n-1}R_t^{(n)}$,把所有权重压到 $[0,1]$ 且和为 1 |
| 前向视图 | 用 $λ$-回报当目标(概念直观,但**因果不可实现**) |
| 后向视图 | 用资格迹 $e_t(s)$ 把每个 TD 误差散回最近访问过的状态(因果、增量、在线可算) |
| 累积迹 / 替换迹 | 重复访问时 $e$ 是"累加"(可能 > 1)还是"重置为 1"(恒 ≤ 1) |
| 迹衰减参数 $λ$ | $λ=0$ 退化成 TD(0),$λ=1$ 退化成每次访问蒙特卡洛 |

历史:资格迹从 Sutton 1988 的 TD(λ) 起就是 TD 家族的核心机制;它也是 GAE
(见同级 [ActorCritic与GAE/](../ActorCritic与GAE/))在现代策略梯度里的直接前身 ——
GAE 的 $λ$ 就是这里的 $λ$。

## 原理详解

### 1. $n$ 步回报

$$
R_t^{(n)} = r_{t+1} + γr_{t+2} + \dots + γ^{n-1}r_{t+n} + γ^n V_{t+n-1}(s_{t+n})
$$

$n=1$ 就是 TD(0) 的目标 $r_{t+1}+γV(s_{t+1})$;$n→∞$ 就是蒙特卡洛回报。
Sutton & Barto §7.1 明确列出 $n$ 步回报并与 TD(0)、MC 对比:中间 $n$ 的误差往往最小。

### 2. $λ$-回报(前向视图)

$$
R_t^λ = (1−λ)\sum_{n=1}^{∞} λ^{n-1} R_t^{(n)}
$$

权重 $(1−λ)λ^{n−1}$ 几何衰减、总和为 1。两个极端:

- $λ=0$:权重全在 $n=1$ 上 → $R_t^0 = r_{t+1}+γV(s_{t+1})$,即 TD(0)
- $λ=1$:权重均匀铺满全程 → $R_t^1 = \sum_{k}γ^k r_{t+k+1}$,即 MC 回报

§7.2 指出它是**非因果**的:每一步都要用后面很多步的信息,所以不能直接在线实现。

### 3. 后向视图(资格迹)

$$
e_t(s) = γλ\,e_{t-1}(s) + \mathbb{1}(S_t = s) \quad \text{(7.5)}
$$
$$
δ_t = r_{t+1} + γV(S_{t+1}) − V(S_t) \quad \text{(7.6)}
$$
$$
V(s) \leftarrow V(s) + α\,δ_t\,e_t(s) \quad \text{for all } s \quad \text{(7.7)}
$$

一句话:**每步只算一个 TD 误差 $δ_t$,却更新所有最近访问过的状态**,权重由迹决定。
$λ$ 因此被原文称为 trace-decay parameter。

### 4. 前向视图 = 后向视图(§7.4)

在**离线**更新下(整条轨迹跑完再统一更新)两者**完全等价**;在线时后向视图是前向视图的近似。
本 demo 的 E2 逐状态比较两者的增量,最大差 **2.11e-15**(浮点噪声级别):

| λ | 0.0 | 0.3 | 0.7 | 0.9 | 1.0 |
| --- | --- | --- | --- | --- | --- |
| 最大逐状态增量差 | 0.00e+00 | 2.11e-15 | 5.42e-18 | 1.13e-17 | 0.00e+00 |

两个端点是**精确**相等($λ=0$ 的后向视图就是 TD(0);$λ=1$ 就是每次访问 MC),
中间 $λ$ 只有浮点级误差 —— 这正是 "equivalence" 该有的样子。

### 5. 累积迹 vs 替换迹(§7.8)

- **累积迹**:$e_t(s) = γλe_{t-1}(s) + \mathbb{1}(S_t=s)$。同一状态反复访问,迹会**叠加超过 1**。
- **替换迹**:**每次访问把迹置回 1**(原文 Eq. 7.16);Singh & Sutton 变体还要把同状态下其它动作的迹清零(Eq. 7.17)。

替换迹的直觉:一个状态"被访问过"这件事,重复两次不应该让它获得双倍资格。
实测(λ=0.9,100 回合):**替换迹 0.0393 < 累积迹 0.0602**,而且累积迹峰值能到 **2.47~5.08**,
替换迹恒 **≤ 1.000**。

### 6. 本 demo 的任务:19 状态随机游走

S&B Figure 7.2 的经典例子:19 个非终止状态排成一行,走到最左端终止(奖励 0)、
走到最右端终止(奖励 1),其余步奖励 0,初始 $V=0.5$。真实值函数是 **$V(s) = s/20$**
(线性),因此 RMS 误差有闭式参照。

## 对比 / 选型

| 方法 | 目标 | 偏差 | 方差 | 在线可算 | 数据效率 |
| --- | --- | --- | --- | --- | --- |
| TD(0) | $r+γV(s')$ | 大(自举偏差) | 小 | 是 | 高 |
| $n$ 步 TD | 固定 $n$ | 中 | 中 | 需等 $n$ 步 | 中 |
| TD(λ) 后向视图 | 混合 | 由 $λ$ 控制 | 由 $λ$ 控制 | **是**(增量) | 高 |
| TD(λ) 前向视图 | 混合 | 同后向(离线等价) | 同后向 | 否(非因果) | 需整条轨迹 |
| MC | 实际回报 | 无 | 大 | 否 | 低 |

**$λ$ 是要调的**:本 demo 的 RMS 误差在 $λ \in (0,1)$ 内部取到最优($λ=0.8$),

| λ | 0.0 | 0.2 | 0.4 | 0.6 | 0.8 | 0.9 | 0.95 | 1.0 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| RMS | 0.1251 | 0.1025 | 0.0752 | 0.0445 | **0.0315** | 0.0531 | 0.0838 | 0.3014 |

两端都差(0.1251 / 0.3014),最优在内部且偏大 —— 与 S&B §7 的结论一致。

## 关键代码片段

```python
def lambda_returns(V, states, rewards, gamma, lam):
    """λ-回报的后向递推:gl[t] = r_t + γ[(1−λ)V[s_{t+1}] + λ·gl[t+1]]"""
    T = len(rewards)
    gl = [0.0] * (T + 1)
    for t in range(T - 1, -1, -1):
        v_next = V[states[t + 1]]
        gl[t] = rewards[t] + gamma * ((1.0 - lam) * v_next + lam * gl[t + 1])
    return gl


def lambda_returns_direct(V, states, rewards, gamma, lam, m):
    """(7.3) 定义式:(1−λ)Σ_{n=1}^{m−1} λ^{n−1}R^{(n)} + λ^{m−1}R^{(m)}"""
    out = []
    for t in range(len(rewards)):
        acc = 0.0
        for n in range(1, m):
            acc += (lam ** (n - 1)) * n_step_return(V, states, rewards, t, n, gamma)
        acc *= (1.0 - lam)
        acc += (lam ** (m - 1)) * n_step_return(V, states, rewards, t, m, gamma)
        out.append(acc)
    return out


def td_lambda_offline(V, states, rewards, alpha, gamma, lam, trace="accumulating"):
    """后向视图,离线:跑完整条轨迹,用资格迹把每个 δ 散回最近访问过的状态。"""
    T = len(rewards)
    e = [0.0] * len(V)
    for t in range(T):
        s, s2 = states[t], states[t + 1]
        delta = rewards[t] + gamma * V[s2] - V[s]
        for i in range(len(e)):
            e[i] *= gamma * lam                     # ① 所有迹先衰减
        if trace == "accumulating":
            e[s] += 1.0                             # ②a 累积迹:自增
        else:
            e[s] = 1.0                              # ②b 替换迹:重置为 1
        for i in range(len(V)):
            if e[i]:
                V[i] += alpha * delta * e[i]        # ③ 一个 δ 更新所有"有资格"的状态
    return V
```

## 性能与边界

实测(`python main.py`,19 状态随机游走,100 回合 × 20 次重复取中位;完整表格见 [NOTES.md](./NOTES.md)):

- **E1 $n$ 步 TD 的 RMS**:$n=1$ 0.1258 · $n=4$ **0.0386** · $n=16$ 0.0800 · $n=∞$ 0.2791;
  中间 $n$ 比 TD(0) 好 **3.3 倍**、比 MC 好 **7.2 倍** —— "$n$ 步回报要折中"的量化。
- **E2 前向/后向等价**:$λ=0$ / $λ=1$ 精确相等(0.00e+00),中间 $λ$ 最大差 2.11e-15。
- **E3 最优 $λ$**:$λ=0.8$ 的 RMS **0.0315** 最小;两端 0.1251 / 0.3014 都差。
- **E4 替换迹 0.0393 < 累积迹 0.0602**;累积迹峰值可到 2.466~5.08,替换迹恒 ≤ 1.000。
- 空间 $O(|S|)$ 个迹;时间上每步只算一个 `δ` 但要更新所有迹非零的状态 —— 稠密实现 $O(|S|)$/步。

## 注意事项与常见坑

1. **`λ`-回报的递推尾巴容易写错**。定义式(7.3)在有限视界下是 `(1−λ)Σ_{n=1}^{m−1}λ^{n−1}R^{(n)} + λ^{m−1}R^{(m)}`
   —— 最后一项**不能**再乘 `(1−λ)`,否则尾部被吞掉(开发期实测误差 9.20e-02);写完必须拿递推式
   与定义式互相照(本 demo 最大差 2.78e-16)。
2. **前向/后向只在离线等价**。在线逐步更新时两者只是近似;断言必须限定在离线口径下做。
3. **替换迹的两种版本**要分清:单纯"置 1"(Eq. 7.16)与"置 1 并把同状态其它动作清零"
   (Singh & Sutton, Eq. 7.17);动作值预测用前者会漏掉后者的修正。
4. **累积迹可以超过 1**,这是定义决定的、不是 bug;但若代码里假设 `e ≤ 1`(如拿迹当概率用)就会出错。
5. **浮点等值断言要给容差**。$λ=0$ / $λ=1$ 两端恰好**精确**相等(两条路径退化成同一串运算),
   但中间 $λ$ 只能给 `< 1e-9` 容差(实测 2.11e-15)。
6. **别把 `λ` 和 `γ` 搞混**:$γ$ 折扣奖励、决定问题视界;$λ$ 折扣"信用分配回溯的距离"、只影响学习算法。
