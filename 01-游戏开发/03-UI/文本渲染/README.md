# 文本渲染（游戏 UI）

游戏 UI 文本渲染的核心链路：**矢量字形轮廓 → 光栅化/距离场 → 纹理图集缓存 → 顶点拼版批量绘制**，再叠加排版（换行/富文本）与特效（描边/阴影/发光）。
