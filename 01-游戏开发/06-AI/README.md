# 游戏 AI（非数据驱动）

传统游戏 AI 是**规则驱动**的决策系统，与 ML 路线不同。

## 经典模型

| 模型 | 特点 |
| --- | --- |
| 状态机（FSM） | 简单、确定性强 |
| 行为树（BT） | 模块化、易调试 |
| 决策树 | 数据驱动版 BT |
| 效用系统（Utility AI） | 基于评分的灵活选择 |
| GOAP | 目标导向行动规划 |
