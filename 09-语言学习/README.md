# 09 语言学习

> 与 01-08 按"领域/知识点"组织不同,本目录按**编程语言**组织。
> 目的:沉淀每种语言的**语言机制级**知识点(语法糖、运行时特性、标准库惯用法),与"领域原理"互补。

## 为什么单独建这个维度?

- **领域目录**关心"这件事怎么做" —— 比如 IO 多路复用、REST 设计、碰撞检测
- **语言目录**关心"这种语言本身的写法与坑" —— 比如装饰器、GIL、生成器、async/await、错误处理

两者经常交叉:同一知识点(IO 多路复用)在不同语言里有完全不同的写法。领域目录里的 demo 通常已经覆盖了主流语言,但**只触及该知识点的相关 API**;本目录会深入到"语言本身的特性",不受具体场景限制。

## 目录内约定

每种语言的子目录内部:

```
Python/
├── README.md            # 语言特性总览 + 学习路径 + 与其他语言的关键差异
├── 装饰器/              # 一个语言特性 = 一个 demo
│   ├── README.md
│   ├── basic.py
│   └── with_args.py
├── 生成器/
└── ...
```

单 demo 文件不超过 300 行,优先用标准库。

## 与已有 demo 的边界

- **领域 demo 里同语言的实现**:聚焦在该知识点,**不展开**语言其他特性
- **本目录的 demo**:可以引用领域 demo,但核心目的是讲透**语言本身**

例如:
- `01-游戏开发/01-服务端/网络编程/IO多路复用/select/` 里的 `python/select_echo.py` 只讲怎么用 `selectors` 监听 fd
- `09-语言学习/Python/装饰器/` 讲的是 Python 函数是一等对象 + 闭包 + 语法糖,跟 IO 完全无关
