# SAT 与 EPA —— 分离轴定理与扩张多胞体算法

## 简介

凸形状碰撞检测的两块基石，解决的其实是两个不同的问题：

- **SAT（Separating Axis Theorem）**回答"相交了吗"，顺带给出**最小平移向量 MTV**（往哪推、推多少能把两者分开）。
- **EPA（Expanding Polytope Algorithm）**在 GJK 已经判出相交之后，回答"穿透多深、法线朝哪"，即真正喂给物理求解器的**接触流形**信息。

两者的结论在同一个问题上是一致的：对两个凸多边形，SAT 的最小重叠量 = EPA 的穿透深度，SAT 的 MTV 轴 = EPA 的法线。本 demo 用这两条**互相独立**的路径对拍，作为正确性证据。

本目录：`main.py`（模型）+ `selfcheck_sat_epa.py`（70 项断言，实跑全绿）。

## 原理详解

### 一、SAT：投影找不重叠的轴

原文表述：

> If two convex objects are not penetrating, there exists an axis for which the projection of the objects will not overlap.

三点构件：

1. **待检轴 = 两个形状各自边的法线**。边向量 `edge = p1 - p2`，法线用 `perp: (x, y) => (-y, x)`。原文特别提示：只要布尔结果时**可以不归一化**，但要拿 MTV 就必须归一化，否则重叠量会被轴长缩放。
2. **投影 = 顶点与轴点积的 min/max**（原文 `project`）。
3. **任一根轴上投影不重叠 → 立刻判分离并提前退出**。原文强调这个 early exit 让 SAT 特别适合"物体多、碰撞少"的场景（游戏、仿真）。反过来说，**判定相交必须把所有轴都测完**。

MTV = 重叠量最小的那根轴 + 该重叠量，可以在同一次遍历里顺手记下来。

### 二、两个必须知道的补丁

**1）平行轴去重。** 原文的 "Other Things To Note"：矩形实际只需测 2 根轴而不是 4 根。本 demo 的 `dedupe_axes` 用 `|dot(a,b)| > 1-eps` 判平行，单位正方形确实从 4 降到 2。

**2）包含（containment）修正 —— 最容易漏的一个坑。** 当一个形状整个被另一个包住时，纯"最小重叠"给出的 MTV **不够把形状推出去**。原文的做法是在重叠量上再加一项：

```text
mins = |p1.min - p2.min|
maxs = |p1.max - p2.max|
o += (mins < maxs) ? mins : maxs
```

原文还提醒：加完之后**可能要把分离轴反过来**。本 demo 统一把轴定向成"从 a 指向 b"。

实测（大正方形 `(0,0)-(4,4)` 包住小正方形 `(1,1)-(2,2)`）：

| 写法 | MTV 深度 | 按此深度推开后 |
| --- | --- | --- |
| 不做包含修正 | 1.0 | **仍相交**（不够用） |
| 做包含修正 | 2.0 | 恰好分离（少推 ε 仍相交，多推 ε 分离） |

原文给了两条理由：① 这种构型**真的可能发生**，不处理就需要多次迭代才能解开；② 如果要支持线段（厚度为 0 的形状），重叠量可能算出来是 0，**必须**处理。

### 三、曲边形状

- **圆 vs 圆**：只需 1 根轴 —— 圆心连线。判据退化成 `|c1-c2| < r1+r2`，穿透深度 = `r1+r2-d`。
- **圆 vs 多边形**：光有多边形的边法线**不够**。原文要求额外补一根"**最近顶点 → 圆心**"的轴。实测：圆心 `(1.2,1.2)`、半径 `0.2` 贴着单位正方形的右上角外侧（到角点距离 0.283 > 0.2，实际不相交），只测多边形轴会**误报相交**，补上这根轴才判对。
- 胶囊等更复杂曲边，原文建议分解成矩形 + 两个圆。

### 四、EPA：在 Minkowski 差上扩张

与 GJK 一样走 Minkowski **差**（不是和），沿用同一个支撑函数。区别是：**EPA 的单纯形点数不限**（GJK 最多 3 个/4 个），2D 起步必须是**完整的三角形**，3D 必须是四面体 —— 可以直接拿 GJK 的终止单纯形。

每轮：

1. 找距原点最近的那条边，用三重积求外向法线
   `n = (e × oa) × e = oa(e·e) - e(oa·e)`，归一化，`distance = n·a`；
2. 沿 `n` 取支撑点 `p`；
3. 若 `p·n - distance < TOLERANCE` → 收敛，`normal = n`，`depth = p·n`；
4. 否则把 `p` **插在构成最近边的两点之间**（`index = j`，即下一点的下标），继续扩张。

原文说得很清楚：收敛时最近那条边就躺在 Minkowski 差的边界上，该边的垂距就是穿透深度。容差是必需的 —— 曲边的 Minkowski 差上，单纯形会不断长出越来越小的边去贴合曲率，永远收敛不到精确值。

### 五、官方算例复算（口径说明）

dyn4j 的 EPA 一文给了完整手算过程，本 demo 逐格复现。注意原文数字是**用了四舍五入后的法线分量**再点积得到的，本 demo 用精确值：

| 量 | 原文（四舍五入分量） | 精确值 |
| --- | --- | --- |
| 第 1 轮最近边距离 | 0.62 | 0.6324555320336759 |
| 第 1 轮法线 | (-0.32, 0.95) | (-0.31622776601683794, 0.9486832980505138) |
| 第 2 轮最近边距离 | 0.94 | 0.9370425713316364 |
| 第 2 轮法线 | (0.62, -0.78) | (0.6246950475544243, -0.7808688094430304) |
| 深度 `p·n` | 0.92 | 0.9370425713316364 |

第二轮插入的支撑点 `(4,2)` **恰好就是单纯形已有的顶点**，因此 `p·n` 与该边距离严格相等、差值为 0，是最干净的收敛签名。

### 六、三重积退化：不是纸面假设

原文的 "Winding and Triple Product" 一节警告：**小碰撞/接触碰撞**会让原点几乎贴在最近边上，三重积退化成零向量，归一化时**除零**。

本 demo 实测了两件事：

1. 构造单纯形 `(1,0) (-1,0) (0,2)`（第一条边过原点），三重积写法**真的抛 `ZeroDivisionError`**，保 winding 的替代写法返回距离 0 与单位法线，不崩。
2. 在**真实多边形数据**上跑 GJK→EPA（两个轴对齐正方形角落重叠 1×1），三重积写法同样崩 —— 这个坑在日常数据里就会遇到，不是理论边角。

替代做法：直接取边的垂线 `perp(e)`，再用 winding 决定符号（保证法线落在原点那一侧）。数学上与三重积**完全等价**（三重积就是 `oa` 去掉沿 `e` 的分量后剩下的垂向分量），但避开了除零。本 demo 断言两种写法在非退化输入上给出**同一个**最近边（距离与法线都一致）。

## 对比

| | SAT | EPA（需先跑 GJK） |
| --- | --- | --- |
| 输入 | 两个凸形状的顶点 | Minkowski **差**上的支撑函数 + 终止单纯形 |
| 输出 | 布尔 + MTV（轴 + 深度） | 法线 + 穿透深度 |
| 复杂度 | 轴数 = 两边数之和，O(n·m) 次投影 | 迭代扩张，每轮一次支撑查询 |
| 提前退出 | 有（找到分离轴即返回） | 无（要贴到边界才收敛） |
| 适用 | 多边形/圆，2D 最常用 | 任意能用支撑函数表达的凸体（含多面体、圆柱） |
| 曲边 | 要特判（圆-圆、圆-多边形） | 天然支持，靠容差收敛 |

对**同一对凸多边形**，两者给出同一个最小穿透 —— 本 demo 在 3 组构型上对拍，法线同轴（`|dot| = 1`）且深度差 < 1e-6。

## 关键代码

```python
# SAT：遍历两边法线，记最小重叠（含包含修正）
def sat(a, b, reduce_parallel=False, use_containment=True):
    axes = get_axes(a) + get_axes(b)
    if reduce_parallel:
        axes = dedupe_axes(axes)
    smallest = None; best = None
    for axis in axes:
        o, _ = overlap_amount(project(a, axis), project(b, axis), use_containment)
        if o is None:
            return None                      # 找到分离轴 -> 提前退出
        if best is None or o < best:
            best, smallest = o, axis
    if dot(sub(center(b), center(a)), smallest) < 0:
        smallest = neg(smallest)             # 统一定向：从 a 指向 b
    return (smallest, best, len(axes))

# EPA：三重积求外向法线，收敛判据 p·n - distance < TOLERANCE
def find_closest_edge(simplex):
    closest = None
    for i in range(len(simplex)):
        j = (i + 1) % len(simplex)
        a, b = simplex[i], simplex[j]
        e = sub(b, a)
        n = norm(triple_product(e, a, e))    # (e × oa) × e = oa(e·e) - e(oa·e)
        d = dot(n, a)
        if closest is None or d < closest[0]:
            closest = (d, n, j)
    return closest
```

## 性能边界

- **SAT**：轴数 = `n + m`（去重后更少），每次投影 O(顶点数)，总体 O((n+m)·(n+m))。绝大多数物体对在第 1~2 根轴就退出，因此实际远快于上界。
- **EPA**：每轮一次支撑查询（O(顶点数)）+ 一次全边扫描（O(单纯形点数)）；单纯形点数随曲率增长，**曲边可能长出很多小边**才收敛，是 EPA 的主要开销来源。
- 两者都只适用于**凸**形状；非凸必须先做凸分解（原文 Figure 3），再逐块测试。
- 3D SAT 的待检轴数量会爆炸（原文："SAT in 3D can end up testing LOTS of axes"），工程上 3D 通常走 GJK/EPA。

## 注意事项与常见坑

1. **忘了归一化轴** —— 只要布尔结果没事，一拿 MTV 就错，重叠量被轴长整体缩放。
2. **漏了包含修正** —— 一个形状被完全包住时 MTV 不够用（实测差 2 倍），需要多轮迭代才能解开，表现为"物体卡在一起抖"。
3. **圆-多边形只测多边形轴** —— 会在角点附近**误报**（实测贴角场景）。必须补"最近顶点 → 圆心"轴。
4. **MTV 方向反了** —— 尤其做了包含修正之后。本 demo 统一按质心连线定向，但真实引擎里要按"谁推谁"的约定来。
5. **EPA 喂进去的不是完整三角形** —— 2D 必须 3 点、3D 必须 4 点；GJK 需要保证在构造出三角形之后才报"相交"。
6. **三重积除零** —— 实测在真实数据上就会发生。要么用保 winding 的替代写法，要么加退化检测；单纯 `try/except` 会吞掉真正的精度问题。
7. **容差取值** —— 太小会让曲边场景迟迟不收敛，太大会让穿透深度偏浅；原文给的参考量级是 `1e-5`。
8. **接触（刚好贴着）算不算相交** —— 本 demo 的闭区间投影把它判为相交、深度 0。真实引擎里通常用 `linearSlop` 之类的容差把这类接触直接吃掉（见同目录的接触求解 demo）。
