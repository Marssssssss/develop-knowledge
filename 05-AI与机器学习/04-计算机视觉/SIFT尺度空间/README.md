# SIFT 尺度空间(Scale-Invariant Feature Transform)

## 简介

SIFT 由 David Lowe 提出,是第一个把**尺度不变**、**旋转不变**与**对光照/视角变化稳健**同时做到的
局部特征。它的价值不在某个算子多精巧,而在于一套完整的可工程化流水线:
构建尺度空间 → 找尺度空间极值 → 亚像素定位并剔除低对比度/边缘响应 → 分配主方向 →
生成 128 维描述子 → 最近邻/次近邻距离比匹配。

本目录用**纯标准库**从零实现这条流水线(Python + Go),不做图像 I/O 依赖;
论文里的每个数字都写成可执行断言,自检 62 条。

```
python/  sift.py(1~4 步:金字塔/DoG/极值/定位/边缘剔除)  descriptor.py(5~6 步:方向/描述子/匹配)
         sift_check.py(自检 A~I 九段)
go/      sift.go localize.go keypoint.go descriptor.go(实现,同一 main 包)
         checkutil.go check_desc.go main.go(自检)
```

> Go 侧拆 7 个文件是为守住「单文件 ≤ 300 行」的仓库硬约束,它们属同一 `main` 包,用 `go run .` 一次编译。

## 原理详解

### 1. 为什么必须是高斯

Koenderink(1984)与 Lindeberg(1994)证明:要使尺度空间满足**因果性**(粗尺度不引入细尺度才有的结构)
且线性、平移不变,平滑核**只能**是高斯,于是 `L(x, y, σ) = G(x, y, σ) * I(x, y)`。
本 demo 把核截断到 **3σ**(约丢 0.3% 能量),核长 `2·ceil(3σ)+1`:σ=1.6 时为 **11**,核和归一化到 1。

### 2. 为什么可以用 DoG 近似 LoG

热方程给出 `∂G/∂σ = σ∇²G`,故对 σ 求导可用差分替代:

```
D(x, y, σ) = L(x, y, kσ) - L(x, y, σ) ≈ (k - 1) σ² ∇²G * I
```

右端正是**尺度归一化** LoG(乘 σ² 才让不同尺度的响应可比)。关键结论:因子 `(k-1)` 与尺度无关,
只整体缩放幅度、不改变极值位置 —— 这就是能不额外算 LoG 就做尺度检测的原因。
自检 B 段用解析高斯量化近似质量:

| k | DoG 与 (k-1)σ²∇²G 的相关系数 | 面积幅度比 |
|---|---|---|
| 1.02 | 0.999878 | 0.9913 |
| 1.10 | 0.997219 | 0.9558 |
| 1.26 (=2^(1/3)) | 0.984315 | 0.8861 |
| 1.40 | 0.968154 | 0.8362 |

即 k → 1 时**相关系数与幅度比同时单调趋近 1**。论文取 s = 3 得 k = 2^(1/3) ≈ 1.2599,相关仍有 0.984。

### 3. 数据结构:s+3 张模糊图 → s+2 张 DoG

每 octave 的尺度序列为 `σ, σk, σk², …, σk^(s+2)`;由 `σ·k^s = 2σ` 可知**必须生成 s+3 张模糊图**
才能凑出覆盖完整 octave 的 s+2 张 DoG。降采样取第 s 张(σ 恰为 2σ),按行列隔点重采样后有效 σ
回到 σ,于是下一个 octave 精度不变而计算量降到 1/4。自检 A 段:σ0=1.6000 → σ3=3.2000;k³ = 2;
6 张模糊 → 5 张 DoG;尺寸 32 → 16 → 8 → 4。

### 4. 26 邻居极值

候选点与**同层 8 邻居 + 上下层各 9 邻居**共 26 个比较;这使首尾两层**天然不可用**,
也解释了为何要多生成 3 张模糊图。负峰(极小值)同样被检出,平坦区域无极值。

### 5. 亚像素定位与两级剔除

对 D 做二阶 Taylor 展开并令导数为零:`x̂ = -H⁻¹(∂D/∂x)`,`D(x̂) = D + ½(∂D/∂x)ᵀx̂`。

- 偏移**任一维 > 0.5** → 真极值更靠近相邻采样点,须换点重做插值(本 demo 标记 `need_resample`);
- `|D(x̂)| < 0.03` → 低对比度丢弃(像素值在 [0, 1])。

自检 D 段:真偏移 (0.3, 0.2, 0.2) 恢复为 (0.2862, 0.1897, 0.1897),最大误差 **0.0138 < 0.03**;
幅度 0.02 剔除、0.05 保留;**偏移恰为 0.5 时不换点**(论文判据是 strictly > 0.5)。

边缘剔除用 2×2 Hessian。令 α、β 为主曲率,r = α/β,则

```
Tr(H)² / Det(H) = (r + 1)² / r     Tr(H) = Dxx + Dyy     Det(H) = Dxx·Dyy - Dxy²
```

该比值**只依赖 r**,无需显式求特征值;`(r+1)²/r` 在 r = 1 取最小值 **4**、随 r 增大而增大,
论文取 r = 10 → 阈值 **12.1**,只有 `< 12.1` 才保留。自检 E 段:对称隆起恰为 4.000000000000;
细长隆起 σy=6 得 **16.516** 被剔除、σy=4 得 8.631 保留;`Det ≤ 0`(曲率异号)直接剔除。

### 6. 主方向:36 bin + 80% 判据

围绕关键点统计梯度方向直方图:**36 bin 覆盖 360°**(每 bin 10°),样本按**梯度幅值加权**,
再乘 **σ = 1.5 × 关键点尺度** 的圆形高斯窗。取最高峰;凡是**达到最高峰 80% 的局部峰**也各生成一个
关键点(同位置、同尺度、不同方向)——论文实测仅约 **15%** 的点被赋多方向,但它们显著提升匹配稳定性。
最后对峰附近 3 个直方图值**拟合抛物线**做亚 bin 插值。自检 F 段:30° 落入 bin 3;
次峰 85% → 2 个关键点、79% → 1 个;抛物线插值对真抛物线可**精确**还原 0.1 个 bin 的偏移。

### 7. 128 维描述子与光照不变

关键点周围取 **16×16** 采样、按主方向旋转对齐,分 **4×4 = 16 子块**,每块 **8 个方向 bin**,
合起来 **4×4×8 = 128** 维;子块内用**三线性插值**(每维权重 `1-d`)避免边界突变。
窗口高斯权重 σ 取**窗口宽度的一半**,压低受配准误差影响最大的外围梯度。

光照不变是**两步**:①向量**单位化** → 抵消对比度线性缩放(亮度整体平移本就不影响梯度);
②每分量**截到 0.2** → 再**重新单位化** → 抑制非线性光照/饱和造成的大梯度。

> 这一步的真实语义常被误解:截断发生在**最终归一化之前**,所以「每分量 ≤ 0.2」**不是**描述子的
> 最终性质 —— 重新单位化后分量可以**超过 0.2**。自检 H 段用两根非零分量的极限例子钉住这点:
> 截断前两分量比 1.111111 被抹平为 1.000000,而重归一化后最大分量达 **0.7071**。

匹配用**最近邻/次近邻距离比**:`d₁/d₂ > 0.8` 拒绝;论文称可剔除约 **90% 错误匹配**,
而只丢不到 **5% 正确匹配**。自检 G 段另钉住不变性:整体幅值 ×7 后描述子最大差异 **1.11e-16**
(归一化抵消);位置 + 梯度 + 关键点角同时旋转 90° 后取值集合最大差异 **2.78e-17**。

## 对比

| 维度 | SIFT | Harris(本类目 043) | ORB / BRIEF 类 |
|---|---|---|---|
| 尺度不变 | 是(DoG 金字塔) | 否(需手工搭金字塔) | 是(oFAST + 金字塔) |
| 旋转不变 | 是(主方向对齐) | 否 | 是(带方向的 BRIEF) |
| 描述子 | 128 维 float | 无(只有响应值) | 256 位二进制 |
| 匹配代价 | 欧氏距离 | — | 汉明距离(极快) |
| 定位精度 | 亚像素(Taylor) | 亚像素(二次拟合) | 像素级 |

与 Canny(本类目 042)的关系:两者都从高斯导数出发,但 Canny 的 NMS 在**单张图的梯度方向**上做,
SIFT 的极值判定在**尺度轴 + 空间**的 3×3×3 邻域做 —— 多出的那一维正是尺度不变性的来源。

## 性能与边界

设图像边长 N、每 octave 有 s+3 张模糊图。第 o 个 octave 像素数为 `N²/4^o`,于是金字塔构建的总
卷积量 ≈ `N²(1 + 1/4 + 1/16 + …) × (s+3) ≈ 8N²`(s=3),即**与原图同阶**;可分离卷积让每张图的
两趟一维卷积各只需 `O(N²·(6σ+1))`。极值检测为 `4/3·N²·(s+2)` 个 26 次比较量级;
内存驻留 ≈ `(s+3)·4/3·N²` 个浮点(s=3 时约 8N²)。

适用边界:**模糊图像** —— σ 是从「假设输入已被 σ=0.5 模糊」往上叠的,输入本身已糊则细节层被吃掉;
**重复纹理** —— 128 维描述子会大量近邻并列,比率判据把它们全部拒绝(这是特性不是 bug);
**大视角变化** —— 对约 <60° 视角变化稳健,超过后仿射不变性不足,需 ASIFT 一类扩展。

## 注意事项与常见坑

1. **参数不是一回事**:论文的 σ=1.6、contrastThreshold=0.03、r=10 与 OpenCV 默认值**不能直接对齐**。
   OpenCV `SIFT::create` 默认 `contrastThreshold=0.04`,且文档明确写着它**在应用时会除以
   nOctaveLayers**;要等价论文的 0.03 必须传 **0.09**。跨实现比参数前先看清这一步。
2. **边缘阈值方向是反的**:`edgeThreshold` 越大**留下**的特征越多(它是 r 的上界,不是剔除比例),
   与 `contrastThreshold` 越大特征越少的方向相反。
3. **octave 数量**:论文经验值是 4,OpenCV 则**按图像分辨率自动决定**;小图上硬写 4 会让末层只剩几像素。
4. **描述子 clamp 的语义**:见 §7 提示框 —— 截断在重归一化之前,最终分量可 > 0.2。
5. **极值层天然排除首尾**:`s` 只能取 `1..n-2`,不要试图在首尾层找极值。
6. **`offset > 0.5` 的正确处理是「换采样点重做插值」**而非简单丢弃;本 demo 只做标记
   (Python 返回 `need_resample`,Go 侧体现为 `"offset>0.5"` 状态)。
7. **别把 DoG 当 LoG 用**:差异因子 `(k-1)` 给响应带来约 11% 的系统性偏差
   (k=2^(1/3) 时幅度比 0.8861);下游若需绝对幅度(如阈值化)必须自己补上这个因子。
