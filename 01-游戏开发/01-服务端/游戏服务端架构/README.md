# 游戏服务端架构

关注整体架构层面的设计：单服/分线/分服/跨服、网关、房间、匹配、负载均衡。

## 常见架构模式

- **单服单进程**：早期 MMO，适合 1k-3k 在线
- **多线分服**：网关按线路（如 1-100）路由，玩家分流到不同进程
- **分区分服**：硬隔离，最简单但社交受限
- **全区全服 + 微服务**：现代大世界 MMORPG（网易雷火、暴雪 WoW）
- **房间制**：MOBA/FPS 主流，匹配进房 → 战斗结束销毁
