# 01 游戏开发

游戏开发是一个跨学科领域，涉及服务端架构、实时渲染、UI 系统、物理仿真、AI 决策、音频、动画等多个子系统。本目录按子系统横向组织，每个子系统下继续细分。

## 子领域

| 子目录 | 说明 | 状态 |
| --- | --- | --- |
| [01-服务端](./01-服务端/) | TCP/UDP 通信、长连接架构、网关、房间/匹配、数据库与缓存 | 进行中 |
| [02-渲染](./02-渲染/) | 图形管线、着色器、光照阴影 | 进行中 |
| [03-UI](./03-UI/) | UI 系统、布局、事件分发 | 进行中 |
| [04-游戏引擎](./04-游戏引擎/) | Unity / Unreal / Godot / 自研引擎 | 进行中 |
| [05-物理](./05-物理/) | 碰撞检测、刚体与柔体、约束求解 | 待研究 |
| [06-AI](./06-AI/) | 行为树、状态机、寻路（`A*` / `NavMesh`） | 待研究 |
| [07-音频](./07-音频/) | 音频引擎、空间音频、MIDI、混音 | 待研究 |
| [08-动画](./08-动画/) | 骨骼动画、状态机动画、蒙皮 | 待研究 |

## 与其他领域的重叠

- **网络编程**：与 [03-系统编程/01-网络编程/](../../03-系统编程/01-网络编程/) 共享底层机制（如 `select`/`epoll`），但侧重于长连接、心跳、协议打包。
- **数据库**：与 [07-数据存储/](../../07-数据存储/) 共享，但侧重于游戏特有的实体存储（玩家档案、背包、排行榜）。
- **AI**：与 [05-AI与机器学习/](../../05-AI与机器学习/) 共享，但侧重游戏内决策（行为树、状态机），非数据驱动训练。
