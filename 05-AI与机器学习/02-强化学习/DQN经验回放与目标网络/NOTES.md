## 2. 超参是怎么筛出来的

本 demo 的配置不是从论文抄的,是开发期实测筛出来的。记录几条关键筛选:

| 尝试 | 结果 | 结论 |
| --- | --- | --- |
| 固定起点 + 每步奖励 −1 目标 +1 | 网络学出常数 Q ≈ −15,11 条断言中 6 条失败 | "Q 与状态无关"是自洽不动点,必须随机起点 |
| `hid_bias=True`(共享隐藏偏置) | ReLU 整层被推向负饱和 | 改 `hid_bias=False` |
| hidden=24,episodes=700 | full 3/5 完美,no_target 1/5 | 容量偏小 |
| hidden=32,episodes=700,lr=0.05 | full 均值 0.77 | 学习率偏小 |
| **hidden=32,episodes=700,lr=0.1** | **full 5/5 完美** | 采用 |
| lr=0.5 / 1.0 / 2.0(5×5 网格) | 两种配置都学不动,不构成对照 | 高学习率不是好的对照轴 |

一次失败的高学习率对照(5×5、hidden=32、200 回合、5 种子):

| lr | target=Y 成功率 | target=N 成功率 |
| --- | --- | --- |
| 0.5 | 0.04 0.24 0.44 0.12 0.20 | 0.36 0.16 0.00 0.20 0.52 |
| 1.0 | 0.20 0.20 0.04 0.16 0.08 | 0.00 0.00 0.20 0.20 0.00 |

两者都没学会,所以这条轴被放弃;改用 lr=0.1 下的"完美 vs 退化"作为目标网络消融的口径。
**不要把这里没跑出对照的配置写进 README 当结论。**

## 3. 开发期踩坑记录

1. **调用约定错位导致"训练完全不收敛"**。首版 `main.py` 里写的是
   `y = br + GAMMA * max(net.forward_onehot(bs2)[1])` —— `[1]` 是隐藏层激活而不是 Q;
   并且 `online.sgd_step_onehot(bs, h, dq)` 少传了 `pre`。两个错误都不会抛异常,
   只会静默地学出垃圾。**每次写完都要对照函数签名数一遍实参。**
2. **`_hidden_grad` 用了 `self.lr` 而没用调用方传入的 `lr`**,导致
   `sgd_step(..., lr=...)` 的输出层与隐藏层用了不同学习率。已改为显式传参。
3. **终点格不是吸收态**。"终止转移不自举"这条断言一开始是红的,环境返回了
   `(goal, 0.0, False)`;修的是 `GridWorld.step`(加 `if self.state == self.goal: return ... True`)。
4. **`forward_onehot` 要求 `MLP.w1[j][s]` 可索引**,即输入维度必须等于状态数(25 或 16)。
   换网格大小时两处都要改,本 demo 把 `GRID_N` 集中成一个模块常量。

## 4. 与论文的口径差异

| 论文(DQN,Atari) | 本 demo |
| --- | --- |
| 像素输入 + 3 层卷积 + 全连接 | one-hot 状态 + 2 层 MLP(手写前向/反向) |
| RMSProp,minibatch 32 | 朴素 SGD,minibatch 8 |
| ε 在前 100 万帧内从 1.0 线性退火到 0.1 | 在 `episodes*0.5` 内做同样的线性退火 |
| 回放内存 100 万帧,「last N experience tuples」 | 环形缓冲 5000 条 |
| 目标网络每 10⁴ 帧硬拷贝 | 每 50 个环境步硬拷贝 |
| 奖励裁剪到 [−1, 1] | 未裁剪(本 demo 的奖励范围本就是 0/+1) |

数值不可与论文的 Atari 分数类比;可类比的只有**机制层面的结论**。
