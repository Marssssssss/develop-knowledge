# USL 三参数拟合与峰值定位

> 「加机器能加到什么程度」这个问题，USL 给的是一个**带峰值的外推模型**而不是一句"看曲线"。本 demo 从零实现非线性最小二乘拟合（Levenberg–Marquardt + 坐标下降打磨），拟合 R 包 `usl` 自带的两个公开数据集，并**逐项复现已发表系数与统计量**：`α`、`β`、`γ`、残差标准误、Amdahl 渐近线、最优点、峰值点，以及"β 减半后峰值会推到哪"的 what-if。

代码：`python/uslmodel.py`、`python/selfcheck_usl.py`（73 条断言）、`python/main.py`、`go/`（模型与峰值定位的 Go 实现，含两个数据集）。

## 一、模型与三个参数

```text
C(N) = N  / [1 + α(N−1) + βN(N−1)]          # 相对容量 = X(N)/X(1)
X(N) = γN / [1 + α(N−1) + βN(N−1)]          # 三参数绝对吞吐
```

| 参数 | 阶 | 名称 | 成因 |
| --- | --- | --- | --- |
| γ | 0 阶 | Concurrency 并发 | 理想并行度；`α=β=0` 时退化为直线 `X(N)=γN` |
| α | 1 阶 | Contention 竞争 | 共享资源的排队/等待代价 |
| β | 2 阶 | Coherency 一致性 | 分布式资源之间点对点交换数据、使数据变一致的延迟 |

三条派生量（R 包 `usl` 源码里的写法）：

```text
Nmax = √[(1 − α)/β]        Xmax = X(Nmax)      # β = 0 时 Nmax 在无穷远
Nopt = |1/α|               Xopt = X(Nopt)
Xlim = γ · Nopt = γ/α                          # Amdahl 渐近线
```

"β = 0 时峰值在无穷远"是本模型最反直觉也最重要的一条：曲线只是**渐近**到 `1/α`，永远不会掉头。只有 `β ≠ 0`（一致性代价非零）才存在**有限的峰值**，过了这个点**吞吐随负载增加而下降**——这就是 retrograde（倒退）。

## 二、拟合器的实现与对拍

拟合目标 `min Σ(yᵢ − X(Nᵢ))²`，参数边界 `α,β ∈ [0,1]`、`γ > 0`，起始值与 R 包一致（`γ₀ = max(y/x)`、`α₀ = 0.01`、`β₀ = 1e-4`）。

- **主循环**：Levenberg–Marquardt，解析 Jacobian

  ```text
  ∂X/∂γ = N/D          ∂X/∂α = −γN(N−1)/D²          ∂X/∂β = −γN²(N−1)/D²
  ```

  自检里三条偏导都与中心差分对拍（相对误差 < 1e-6）。
- **打磨**：β 常常会撞到 0 边界，此时 LM 的阻尼会过早放大而停在半途（实测只跑到 SSE 706.9，比已发表的 697.2 差 1.4%）。补一轮**坐标下降 + 步长折半**后落到 697.2378，与已发表值一致到小数点后 4 位。

## 三、raytracer：只有竞争、没有一致性

BRL-CAD 光线追踪，1~64 处理器：

| | α | β | γ | SSE | RSE (df=8) |
| --- | --- | --- | --- | --- | --- |
| 本 demo 拟合 | 0.0577708 | 0.0000000 | 21.848844 | 697.2378 | 9.336 |
| R 包 usl 已发表 | 0.057771 | 0.000000 | 21.848843 | 697.2378 | 9.34 |

结论：`β = 0`（撞下边界）→ **没有有限峰值**，吞吐单调趋近 Amdahl 渐近线 `γ/α ≈ 378`；"最优点" `Nopt = 1/α ≈ 17.3`、`Xopt ≈ 195`。

自检里另外对齐了 R 的 `efficiency()` 口径（**观测值 / (γN)**，不是拟合值）：`min = 0.222`（N=64）、`max = 0.915`（N=1），与 vignette 打印的 `0.222 / 0.915` 一致。

## 四、specsdm91：真的会倒退

SPEC SDM91，1~216 虚拟用户：

| | α | β | γ | SSE | RSE (df=4) |
| --- | --- | --- | --- | --- | --- |
| 本 demo 拟合 | 0.0277285 | 0.0001044 | 89.995233 | 27453.72 | 82.846 |
| R 包 usl 已发表 | 0.0277285 | 0.0001044 | 89.9952382 | 27453.83 | 82.8 |

派生量全部对齐：`Nmax = 96.50`（vignette 96.5）、`Xmax = 1883.8`（1880）、`Xlim = 3245.6`（3245/3250）、`Nopt = 36.06`（36.1）、`Xopt = 1542.4`（1540）；效率 `min = 0.0876`、`max = 0.7211` 与 vignette 完全相同。

**峰值公式的独立验证**：在 `N ∈ [1, 400]` 上以 0.01 步长做数值 argmax，得到 96.50，与 `√[(1−α)/β]` 相差 < 0.05。反向也成立：`X(216) = 1646.0 < X(144) = 1821.4 < X(96.5) = 1883.8`，**加负载真的会把吞吐拉下来**。

## 五、what-if：α 与 β 谁该先动

| β | Nmax | Xmax |
| --- | --- | --- |
| 0.0001044（实测） | 96.50 | 1883.8 |
| 0.00005（减半） | 139.45 | 2162.1 |
| 0.00002 | 220.48 | 2463.7 |

`Nmax = √[(1−α)/β]` 里 **γ 完全不出现**（自检里用 γ=10 与 γ=500 两个模型断言 Nmax 相同、Xmax 成正比）——**γ 只缩放 y 轴，定位峰值靠的是 α 和 β**。而 `1 − α` 这一项意味着：**当 α 已经很小（竞争已压到很低）时，再优化锁竞争对峰值几乎没用，剩下的全部空间都在 β（节点间同步/数据一致性）上**。这就是"比较 α 与 β 的相对大小即可判断该去改锁还是该去改同步"的定量版本。

## 六、踩过的坑

- **只有 LM 不够**：β 撞边界时阻尼策略会让迭代提前停在一个明显更差的点上（SSE 差 1.4%），必须再加一轮无导数的打磨。对照已发表统计量（SSE / RSE）是发现这件事的唯一办法——**只看曲线好不好看是看不出来的**。
- **中心差分步长不能统一取 1e-6**：`∂X/∂β` 带 `N²(N−1)`，N=64 时放大到 4e5 量级，h=1e-6 的截断误差就到了 2.3e-6，会把正确的解析 Jacobian 判成错的。实测 h=1e-7 时三项相对误差都 < 1e-7。
- **`efficiency()` 用的是观测值不是拟合值**：用拟合值时 `N=1` 的效率恒为 1.0，与 vignette 的 `max = 0.915` 对不上——差的正是残差那一部分。
- **"已发表系数是极小点"要写成相对差断言**（这里用 `< 1e-5`），不能要求两边 SSE 逐位相等：R 的 `nls`/`nlxb` 收敛容差与我们的不同，specsdm91 上两边相差 0.0004%。
- **Nmax 与 γ 无关**这条常被写反：γ 决定纵轴刻度，只有 α、β 决定峰值横坐标。
