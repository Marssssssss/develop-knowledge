# Groth16 zk-SNARK：R1CS → QAP → 三个群元素

## 1. 简介

Groth16 是 2016 年 Jens Groth 提出的配对型 SNARK，至今仍是「证明最短、验证最快」的方案之一：
**证明只有 3 个群元素，验证只查一个配对乘积等式（3 次配对）**。

本 demo 按论文第 14 页的原始定义实现 Setup / Prove / Vfy：

```
Setup:   α, β, γ, δ, x ← F*
         σ = (α, β, γ, δ, {x^i}_{i=0}^{n-1},
              { (βu_i(x)+αv_i(x)+w_i(x)) / γ }_{i=0}^{ℓ},
              { (βu_i(x)+αv_i(x)+w_i(x)) / δ }_{i=ℓ+1}^{m},
              { x^i·t(x) / δ }_{i=0}^{n-2} )
Prove:   A = α + Σ_{i=0}^{m} a_i·u_i(x) + r·δ
         B = β + Σ_{i=0}^{m} a_i·v_i(x) + s·δ
         C = ( Σ_{i=ℓ+1}^{m} a_i(βu_i(x)+αv_i(x)+w_i(x)) + h(x)t(x) ) / δ
             + A·s + r·B − r·s·δ
Vfy:     A·B = α·β + Σ_{i=0}^{ℓ} a_i(βu_i(x)+αv_i(x)+w_i(x))/γ · γ + C·δ
```

（符号沿用论文：`u_i/v_i/w_i` 是 QAP 的三个多项式族，下标 `0..ℓ` 是**公开输入**，
`ℓ+1..m` 是**见证**，`x` 是秘密求值点。）

## 2. 从 R1CS 到 QAP

R1CS 的形式是：对每条约束 `j`，`<U_j, a> · <V_j, a> = <W_j, a>`，
`a` 是完整赋值向量（`a_0 ≡ 1` 是约定）。

把它变成 QAP：对每个变量 `i`，把它在 `n` 条约束里的取值当作 `n` 个点，
插值出一个多项式 `u_i(X)`（同理 `v_i`、`w_i`）。令 `t(X) = Π_{j}(X − r_j)`，则

```
⟨U_j,a⟩·⟨V_j,a⟩ = ⟨W_j,a⟩ 对所有 j 成立
  ⟺  U(X)·V(X) − W(X) 在 X = r_1 … r_n 处都为 0
  ⟺  t(X) | U(X)·V(X) − W(X)
  ⟺  存在 h(X) 使 U·V − W = h·t
```

**证明「我知道一个满足电路的赋值」就等价于证明「我知道 h 使上式成立」**——
这一步把 `n` 条约束压成了一个多项式恒等式，是 SNARK 能 succinct 的根本原因。

自检里 demo 电路是 `x³ + x + 5 = out`（`out` 公开，3 条约束，4 个变量）：
合法赋值时余式为 0，把 `x²` 改 1 之后余式立刻非零 —— 这条断言把
「为什么伪造证明在代数上不可行」说得很直接。

## 3. 为什么证明只有三个元素

`r`、`s` 是随机的盲化因子。展开 `C` 的定义可以看到：

```
A·B = (α + U + rδ)(β + V + sδ)
    = αβ + αV + βU + UV + δ(…)          ← 其中 αV + βU + UV 正是要证明的东西
```

而 `αV + βU + UV` 里的 `UV − W = h·t`，所以 `UV` 可以用 `W + h·t` 替换：
`W` 拆成公开部分（除以 γ，验证者自己能算）与见证部分（除以 δ，塞进 `C`）。
于是验证者只需把「自己能算的公开部分」加上 `C·δ`，就能复原出 `A·B`。

整个等式里**没有任何一项依赖电路规模**：`A`、`B`、`C` 各是一个群元素，
无论电路有 3 条约束还是 300 万条。自检里把约束数翻倍后断言「证明仍然是 3 个元素」，
这就是 SNARK 的 *succinct*。

## 4. 零知识从哪里来

`r`、`s` 每次随机取。`A`、`B` 里各带一项 `rδ`、`sδ`，`C` 里带
`A·s + r·B − r·s·δ` 这个补偿项，恰好把 `A·B` 里多出来的交叉项抵消掉。
结果：

- 同一个见证、两次证明 → 三个分量**全都不一样**（自检断言）；
- 两个证明都通过验证（自检断言）；
- 验证者看到的只是三个被随机数打散的群元素。

## 5. 有毒废料（toxic waste）

`τ = (α, β, γ, δ, x)` 必须在 setup 之后销毁。论文的 `Sim` 说明了原因：
只要知道 `α, β, δ`，就能**凭空捏造**一个通过验证的证明：

```
任取 A, B，令 C = (A·B − αβ − Σ_{i=0}^{ℓ} a_i(βu_i(x)+αv_i(x)+w_i(x))) / δ
```

自检里这条断言直接跑通了：伪造的 `(A,B,C)` 能通过 `verify`。
注意求和**只覆盖公开输入** `i = 0..ℓ` —— 这是我第一版写错的地方
（写成了见证部分 `ℓ+1..m`），结果伪造不通过。

现实中的缓解手段就是**多方计算仪式（trusted setup ceremony）**：
只要有一个参与者诚实地销毁了自己的那份随机数，整套参数就是安全的。

## 7. 符号双线性群：本 demo 的简化与代价

真实实现跑 BN254 / BLS12-381 的椭圆曲线配对。本 demo 在**符号双线性群**里工作：
群元素记为 `F_p` 里的指数，`e(X, Y)` 记作指数相乘。这样能完整演示
QAP 构造、trusted setup、证明/验证的**代数结构**，但有两个必须知道的代价：

| 代价 | 说明 |
| --- | --- |
| 群是交换的 | 自检里断言了「A、B 互换仍然通过验证」。真实 Type-3 配对下 `A ∈ G1`、`B ∈ G2` 属于不同群，互换根本不合法 |
| 没有离散对数困难性 | 符号模型里能直接相除（`/δ`），真实群上做不到 —— 所以本 demo 演示不了「不知道 τ 就无法伪造」这一点，只能靠 §5 的 `Sim` 说明反面 |

真实配对的实现见同目录 `../BLS聚合签名/`（那里用玩具超奇异曲线跑了真正的 Miller 循环）。

## 8. 关键代码

QAP 的整除判定（整条 SNARK 的地基）：

```python
num = p_sub(p_mul(U, V), W)
h, rem = p_divmod(num, t)
# rem == [] ⟺ 赋值合法
```

验证等式（3 次「配对」）：

```python
lhs = A * B
acc = Σ_{i=0..ℓ} a_public[i] * sigma_public[i]
rhs = alpha * beta + acc * gamma + C * delta
```

## 9. 性能与边界

- Setup：`O(n + m)` 次指数运算，需要把 `σ` 交给你打算证明的每个电路。
- Prove：主导成本是 `h(X)` 的计算与若干多指数运算，与电路规模**线性**相关。
- Verify：3 次配对 + `ℓ+1` 次标量乘，**与电路规模无关**。
- 本 demo 的域是 `p = 2^61 − 1`（梅森素数，取模快），真实 Groth16 用 254 位左右的域。
- 朴素实现：`p_divmod` 是 `O(n²)`，多项式乘法也是 `O(n²)`；
  真实实现用 NTT 做 FFT（可参考 `../后量子MLKEM/` 里的 NTT）。
- **不可用于生产**：没有常量时间保证，也没有真实曲线上的配对。

## 10. 注意事项与常见坑

1. **把 `a_0` 当普通变量**：约定 `a_0 ≡ 1`，公开输入是 `a_0..a_ℓ`，长度是 `ℓ+1` 而不是 `ℓ`。
2. **伪造时求和范围写错**：`Sim` 只覆盖公开输入 `0..ℓ`，写成见证段会算不出通过验证的 `C`。
3. **以为 A/B 可互换**：符号模型里可换（本 demo 断言了这一点），真实 Type-3 配对下不行。
4. **复用 `(r, s)`**：同一个 `(见证, r, s)` 会产出完全相同的证明，等于泄露了确定性；
   每次证明必须重新采样。
5. **把 σ 交给不该拿到的人**：任何持有 `τ` 的人都能伪造证明（§5 已复现）。
6. **以为 SNARK 是后量子的**：Groth16 依赖离散对数假设，**量子计算机可破**。
   后量子方向是 zk-STARK / 基于格或哈希的证明系统。
7. **插值点选得不好**：`roots` 必须两两不同，且与 `t(X)` 的根一致，否则整除判定失效。
