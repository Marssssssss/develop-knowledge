# 01-01 游戏服务端

游戏服务端是网络游戏最复杂的子系统之一：要处理大量并发连接、低延迟同步、防作弊、跨服、持久化等。本目录沉淀相关知识与 demo。

## 子领域

| 子目录 | 说明 |

| [游戏服务端架构/](./游戏服务端架构/) | 单服/分线/分服/跨服、网关、房间、匹配、负载均衡 |
| [数据库与缓存/](./数据库与缓存/) | 玩家档案、背包、排行榜、Redis/MongoDB 应用 |
