## 1. 5×5 网格上的精确软策略迭代(完整表)

设置:5×5 网格,起点左上、目标在 `GOAL=24`(右下),动作数 `|A|=4`,目标奖励 20,`γ=0.95`。
`soft_value_iteration` 迭代到 `1e-13` 收敛(上限 20000 次),得到**精确**软值;
"任务回报"一列是用**硬**策略评估算出的期望折扣任务回报(不含熵项)。

| α | 软值 $V$(起点) | 平均策略熵 | 任务回报(精确评估) |
| --- | --- | --- | --- |
| 0.0 | 13.9667 | 0.0000 | 16.3958 |
| 0.01 | 14.0039 | 0.4393 | 16.3958 |
| 0.1 | 14.3385 | 0.4410 | 16.3955 |
| 0.3 | 15.2007 | 0.6494 | 16.2360 |
| 0.5 | 16.6886 | 1.0604 | 15.1001 |
| 0.7 | 19.6613 | **1.3617** | 8.7338 |
| 1.0 | 27.6147 | 1.3322 | 0.0133 |
| 2.0 | 55.2288 | 1.3306 | 0.0000 |

三条可读的结论:

1. **软值 ≥ 硬最优值**($α\log\sum\exp \ge \max$),且随 $α$ 单调上升;
2. **任务回报随 $α$ 单调不增** —— 这就是最大熵的代价:同样状态数下,$α$ 越大越不愿收敛到最优动作;
3. **$α→0$ 时误差线性趋零**:$\max|V_{soft}−V_{hard}| = 0.37179 / 0.037156 / 0.0037156$
   ($α = 0.1/0.01/0.001$),相邻比值恰好 **10.000** —— 误差是 $O(α)$,不是"大概收敛"而是**线性**。

**第 3 列非单调**:熵在 $α≈0.7$ 见顶(1.3617)后回落到 1.3306 并**饱和**,而不是单调涨到
$\ln 4 = 1.3863$。原因:靠近墙或目标的格子存在**并列**或**差异极大**的动作,
平均熵是"每个状态各自 log-sum-exp 后的熵"再平均,$α→∞$ 时全状态平均熵到不了 $\ln|A|$。
所以"$α$ 越大熵越大"在这类有结构的状态上是**错**的。

## 2. 软 Bellman backup 与 Boltzmann 策略(推导要点)

由最大熵目标出发,软值定义为
$V(s) = E_{a\simπ}[Q(s,a) − α\logπ(a|s)]$;对 $π$ 做约束优化(或直接对 $π$ 求导置零)可得

```
π(a|s) = exp( (Q(s,a) − V(s)) / α )
```

代回 $V$ 的定义即得 $V(s) = α\log\sum_a \exp(Q(s,a)/α)$ —— 这就是**软最大**的来源,
也是为什么"软"值函数必然带 log-sum-exp(用 $\max_a Q$ 代替它,当且仅当 $α→0$)。
$Q$ 的备份仍是 $Q(s,a) = r(s,a) + γ E_{s'}[V(s')]$,只是 $V$ 换了形式。

本 demo 直接断言了 Boltzmann 形式($π$ 与 $\exp((Q−V)/α)$ 的最大差 **0.00e+00**),
以及 $α=0$ 时策略熵为 **0.0000**(退化为确定性贪心)。

## 3. 温度自动调节:约束形式与对偶

手动调 $α$ 的本质困难:奖励的**量级**随任务变、也随策略变好而变,而最优熵依赖这个量级。
原论文把熵写成**约束**(访问到的状态上平均熵 ≥ $H̄$)再取对偶:

```
max_π E[ Σ_t r_t ]   s.t.  E[ −log π(a_t|s_t) ] ≥ H̄  ∀t
        ⟺  min_{α ≥ 0} E_{s_t,a_t∼π*_t}[ −α( log π*_t(a_T|s_T;α) + H̄ ) ]
```

对偶变量就是温度,因此可以像普通参数一样做梯度下降 —— 论文 Algorithm 2 里就是一行
`α ← α − λ ∇̂_α J(α)  ⊳ Adjust temperature`。

本 demo 用**负反馈**形式 `α ← max(1e-6, α − lr·(H − H̄))`:当前熵 $H$ 高于目标 $H̄$ → 括号为正
→ $α$ 减小(更贪心);低于目标 → $α$ 增大。实测三个相差两个数量级的起点
($α_0 = 0.05 / 1.0 / 4.0$)**全部收敛到同一个** $α^* = 0.39009$,最终熵 $H = 0.83178$,
$|H − H̄| = 0.00000$。

## 4. 量纲分析:为什么早期版本的温度更新跑到边界

早期版本用 `goal_reward = 1.0`,温度自动调节停在 `alpha = 1e-6` 边界。
根因是**量纲**:温度固定点取决于 $αH̄$ 与回报的**和**。
- 目标奖励 1.0 时:任务回报量级 ≈ $1/(1−γ) = 20$,而 $αH̄$ 的"有效规模"需要与之可比,
  最优 $α$ 会小到 1e-3 以下,负反馈一路把 $α$ 推到下界;
- 目标奖励提到 20 后:任务回报量级 ≈ 400,两者同量级,$α^* = 0.39$ 落在合理区间。

**这不是超参问题,是量纲问题。**换任务时先算一遍 $r_{scale}/(1−γ)$ 与 $H̄$ 的比值是否可比。

## 5. E4 —— log-sum-exp 的数值边界

$α\log\sum_a\exp(Q/α)$ 里的 $Q/α$ 在 $α$ 小时会到几百:
`math.exp(1000)` 直接 `OverflowError: math range error`。实测:

| 实现 | 输入 $\{Q/α\} = \{1000,1000,1000,1000\}$ |
| --- | --- |
| 朴素 `math.log(sum(math.exp(q) for q in xs))` | `OverflowError`(被 `try/except` 捕获并记为 `overflowed`) |
| 稳定版(先减 $\max$) | **1001.3863** |

校验:$1000 + \log 4 = 1001.38629\ldots$ ✔。这不是理论问题,是**实现时必须处理**的问题;
论文 Appendix 的实测部分同样用到 log-sum-exp 的稳定化写法。

## 6. E2 的两个变体

表格软 Q 学习(off-policy + 回放 + 目标网络)分别用
(a) **期望形式**算目标 $\sum_{a'}\pi(a'|s')[Q(s',a') − α\logπ(a'|s')]$
(b) **采样形式** 用采样的 $a'$ 算目标,
两者都收敛到软策略迭代的不动点,`max gap = 0.00000`(两种变体都是 0)。
结论:软 Q 学习的 off-policy 目标用哪一路估计**不改变不动点**。

注意采样形式需要**期望化**而不是"单样本代入",否则不动点会漂 —— 本 demo 的
`soft_q_learning_via_policy` 就是把单样本目标的期望算出来的版本。

## 7. 开发期踩坑记录

1. **"熵随 $α$ 单调递增"是错的**(见 §1)。第一版写了这条断言,在 $α>0.7$ 后失败。
   正确的分层断言是:(a) 熵 ≤ $\ln|A|$;(b) 任务回报随 $α$ 单调不增;(c) $α$ 大时熵项压倒回报;
   (d) 在 $α$ 较小的区间上熵单调上升。本 demo 把 (a)~(d) 全部写成断言。
   **断言失败先看断言的适用区间,再改实现 —— 但这次确实该改断言。**
2. **温度更新的符号写反不会报错,只会"收敛到另一个值"**。写成 $α ← α + lr(H−H̄)$ 会正反馈发散。
   判据只能是"三个不同起点是否收敛到同一点",单起点看不出方向错。
3. **量纲问题(见 §4)**。把奖励尺度放大 20 倍才稳定。
4. **$α=0$ 必须单独分支**。`logsumexp(q/0)` 直接除零;正确做法是 $α=0$ 时退回 `max`。
   本 demo 断言了 $α=0$ 的软 Q 学习与硬值迭代最大差 **0.00000**。
5. **目标熵的口径要写清**。原论文连续控制取 $H̄ = −\dim(\mathcal{A})$(可为负,那里是**微分熵**);
   离散动作 + 香农熵时目标熵必须 ≥ 0。本 demo 取 $H̄ = 0.8318$($\ln|A| = 1.3863$ 的一部分),
   **与论文数值不可直接比较**。
6. **`main.py` 与 `sac_core.py` 拆分时 import 要同步**。拆分后 `main.py` 仍需
   `from sac_core import move, reward`(这两个函数被断言直接调用),
   漏掉会在运行时报 `NameError`。

## 8. 复杂度与规模边界

| 部分 | 复杂度 | 说明 |
| --- | --- | --- |
| 每步软备份 | $O(\|A\|)$ 的 log-sum-exp | 相比 $\max$ 只多一个 $|A|$ 常数因子 |
| 温度更新 | $O(1)$(每步一个标量梯度) | 几乎不增加成本 |
| `soft_value_iteration` | $O(\text{iters} \times N \times \|A\|)$ | 本 demo 到 1e-13 收敛 |

**规模上限**:本实现为可断言,全部用**精确**表格软策略迭代 + 精确策略评估。
真实 SAC 用两个 Q 网络(双 Q 抑制高估)+ 高斯策略 + 重参数化,规模可到高维连续控制;
本 demo **未复现**论文的 MuJoCo 实验,只采用其目标函数与温度更新形式。
