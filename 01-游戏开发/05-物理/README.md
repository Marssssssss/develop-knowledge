# 游戏物理

物理引擎负责刚体动力学、碰撞检测、布料、流体等。

## 主流物理引擎

- **PhysX**（NVIDIA，Unreal 默认）
- **Bullet**（开源）
- **Havok**（商业，多用于主机）
- **Box2D / Chipmunk2D**（2D）
- **Unity 自带 PhysX / DOTS Physics**
