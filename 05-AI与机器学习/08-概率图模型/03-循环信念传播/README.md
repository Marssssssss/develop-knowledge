# 循环信念传播：收敛判据与消息误差

## 1. 简介

树上跑信念传播（BP）是精确的、且必然收敛；图上有环时两件事都没保证——这就是 loopy BP。但它在实践中又经常好用（Turbo code、立体匹配的成功都靠它），于是需要回答两个问题：**什么时候一定收敛？不收敛时误差会累积成什么样？**

本 demo 按 Ihler, Fisher & Willsky (JMLR 2005) 把这两件事做成可计算的判据，并用「树 = 精确 / 单环 = 必收敛 / 多环强耦合 = 周期 2 振荡」三组对照把它们钉死。

## 2. 原理

### 2.1 消息与信念（Ihler 式 3–4）

```
M^i_ts(xt) ∝ ψt(xt) ∏_{u∈Γt\s} m^i_ut(xt)          # 结点 t 的局部积（不含来自 s 的）
m^{i+1}_ts(xs) ∝ ∫ ψts(xs, xt) M^i_ts(xt) dxt       # 卷积后是 xs 的函数
Mt(xt) ∝ ψt(xt) ∏_{u∈Γt} mut(xt)                    # 信念
```

注意下标方向：`m_ts` 是 **t 发给 s** 的消息、是 `x_s` 的函数；`Γt\s` 是 t 的邻居中**除 s 以外**的那些。写反方向会让整条链静默失效（本 demo 第一版就写反了：结果被当成 `x_t` 的函数，于是「单环必收敛」的定理被自己的实现推翻——这正是「先怀疑被测实现」的价值）。

### 2.2 动态范围：一个对乘法友好的误差度量

```
d(e) = sup_{a,b} sqrt(e(a)/e(b))            log d(e) = ½(sup log e − inf log e)   (Lemma 1)
```

消息是靠**乘法**组合的，所以误差也定义成乘性的 `m̂ = m·e`。`log d(e) = 0` 当且仅当两条消息逐点相等。对归一化消息有 `|log m − log m̂| ≤ 2 log d(e)`（Theorem 2）。

### 2.3 势函数强度与压缩率

```
d(ψts)² = sup_{a,b,c,d} [ψts(a,b)ψts(c,d)] / [ψts(a,d)ψts(c,b)]
```

二元对称势 `[[η, 1−η], [1−η, η]]` 下即 `(η/(1−η))²`（`η = 0.5` 时为 1，表示完全不耦合）。它给出卷积操作一步的**压缩率**（Theorem 8）：

```
d(e^{i+1}_ts) ≤ [d(ψts)²·d(E^i_ts) + 1] / [d(ψts)² + d(E^i_ts)]
```

右端在 `d(E) = 1` 时是 1（无误差 ⇒ 仍无误差），在 `d(E) > 1` 时严格小于 `d(E)`——即**每一次卷积都在缩小误差**，缩小的速率由势函数强度决定。

### 2.4 两个收敛条件

| 条件 | 判据 | 出处 |
| --- | --- | --- |
| **Simon 条件** | `max_t Σ_{u∈Γt} log d(ψ_ut) < 1` | Tatikonda & Jordan (2002)，Theorem 10 |
| **本文条件** | `max_{t,s} Σ_{u∈Γt\s} (d(ψ_ut)²−1)/(d(ψ_ut)²+1) < 1` | Theorem 11（即 `g'_ts(0) < 1`） |

二者关系是**前者蕴含后者**：对 `x ≥ 1` 有 `log x ≥ (x²−1)/(x²+1)`（等号仅在 `x → 1`），且 `Γt\s ⊆ Γt`。所以本文条件更松、判定力更强；在低连接度图上差别明显，在高连接度弱势图上差别可忽略。

**单环图**上每个结点最多两个邻居 ⇒ `|Γt\s| ≤ 1` ⇒ `g'_ts(0) = (d²−1)/(d²+1) < 1` 恒成立 ⇒ **有限强度势下 BP 必收敛到唯一不动点**（Weiss 2000）。Simon 条件在这里太松，证不出这个结论。

## 3. 三组对照（本 demo 实测）

| 模型 | 判据 | 结果 |
| --- | --- | --- |
| 5 结点链（树） | — | 收敛，信念与暴力枚举**逐位相同**（1e-9） |
| 6-环（单环，η=0.75） | `g'(0) = 0.94 < 1` | 收敛，但与真值有 0.04 量级偏差 —— **收敛 ≠ 正确** |
| 双三角（多环，强势） | `g'(0) = 2.00 > 1`、`Simon = 15.2 > 1` | **周期 2 振荡**，`P(A=0)` 给出 0.9999 而真值 0.1118 |

振荡不是靠「跑很多轮没收敛」猜的：自检里直接断言 `m_i` 与 `m_{i−2}` 逐分量相等（差 < 1e-12）而 `m_i` 与 `m_{i−1}` 相差 > 1e-3。

## 6. 关键代码

```python
def message_update(mrf, messages, t, s):
    psi = mrf.psi(t, s)
    out = [0.0, 0.0]
    for xs in (0, 1):                       # 结果是 x_s 的函数
        acc = 0.0
        for xt in (0, 1):
            prod = mrf.node_pot[t][xt] * psi[xs][xt]
            for u in mrf.gamma[t]:
                if u == s:
                    continue
                prod *= messages[(u, t)][xt]     # 计入 t 的其他入消息
            acc += prod
        out[xs] = acc
```

## 7. 性能边界

- 每轮迭代 `O(|E|·K²)`（`K` 为状态数），比变量消除的 `O(d^(w+1))` 便宜得多——这是环上仍要用它的理由。
- 两个判据都**只是充分条件**：本 demo 的 3×3 网格（η=0.9）`g'(0) = 2.93 > 1` 却照样收敛。判据失败不代表不收敛，只代表没有保证。
- 压缩率随 `d(ψ)²` 增大而变差：势函数越强，误差被放大得越多，收敛越慢；`d(ψ)² → ∞`（确定性耦合）时压缩率退化为 1，误差不再缩小。
- 计算树视角：第 `i` 轮的消息对应计算树上第 `n−i` 层的量，所以「迭代次数」≈ 计算树深度，环越多等价于树越深。

## 8. 坑

1. **消息下标方向**：`m_ts` 是 t→s、是 `x_s` 的函数。写反会让「局部积」用错结点的势函数，症状是定理与实现互相矛盾。
2. **`Γt\s` 里的 `s` 是接收方**：计算 t 往外发的消息时，要排除的是**目标结点**那条边，不是自己。
3. **判据是充分的不是必要的**：不要把「判据不满足」当成「会发散」的证据。
4. **周期 2 检测要直接比消息**：只比较「相邻两轮差」是否相等会被非振荡的等比收敛误判；本 demo 比的是 `m_i` 与 `m_{i−2}` 的逐分量差。
5. **`d(ψ)²` 的定义是交叉比**，不是 `max ψ / min ψ`；二元对称势下两者数值相同，但一般势函数上不同。
6. **全对称构造会掩盖一切**：均匀结点势 + 对称边势时所有消息一开始就停在 `[0.5, 0.5]`，任何「收敛」结论都是假的——必须打破对称（给不同结点势）才能测出真实行为。
