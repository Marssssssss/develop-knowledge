# 光照与阴影

让场景有体积感和时间感的关键子系统。

## 经典模型

- **Lambert**：漫反射
- **Phong / Blinn-Phong**：高光
- **Cook-Torrance BRDF**：PBR 物理基础
- **Image-Based Lighting (IBL)**：环境贴图采样

## 阴影技术

- **Shadow Map**：最经典
- **Cascaded Shadow Map (CSM)**：大场景分多级
- **Screen Space Ambient Occlusion (SSAO)**：屏幕空间 AO
- **Contact Hardening Shadows**
