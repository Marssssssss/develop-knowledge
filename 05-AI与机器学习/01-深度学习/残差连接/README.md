# 残差连接 / Identity Mapping

## 简介

残差连接把「让堆叠的层直接学目标映射 `H(x)`」改成「让它们只学残差 `F(x) = H(x) − x`」,再由一条**恒等短路**把输入加回来:`y = F(x) + x`。它的核心价值不是"更多参数"或"更强表达",而是**让梯度与信号能沿恒等通道从任意一层直达任意一层**,从而把"更深更好"这件事从工程难题变成默认选项。

关键概念:

- **退化问题(degradation)**:加深普通网络时,**训练误差**也跟着变高 —— 不是过拟合,而是优化变难。
- **恒等映射**:短路不含任何参数、不增加计算量;`∂y/∂x = I + ∂F/∂x` 里的那个 `I` 就是梯度的"直通车道"。
- **Pre-activation 单元**:把归一化/激活挪到分支内部(`BN-ReLU-Conv`),使相加后仍是恒等映射,是论文正文推荐的排布。
- **短路变体**:把恒等换成缩放(0.9x)或投影(1×1 卷积)都会**抑制输入侧梯度**,实测反而变差。

历史:He 等 2015 年提出 ResNet(152 层拿 ILSVRC 冠军);2016 年同一批作者用消融实验论证「恒等映射不可替换」,并给出 pre-activation 单元。

## 原理详解

### 1. 退化问题

普通网络加深后训练误差上升,说明不是容量不够。论文的表述是"深度网络更难优化",且这个现象与过拟合无关。

本目录用同一套超参复现(固定随机 teacher、同种子、同参数预算、全批量 GD,lr=0.005,250 步):

| depth | plain 初始 → 终值 | residual 初始 → 终值 |
| --- | --- | --- |
| 2 | 13.50 → **7.62** | 53.97 → **4.34** |
| 4 | 16.08 → 7.37 | 78.76 → 1.86 |
| 8 | 14.84 → 7.92 | 113.64 → 1.11 |
| 16 | 17.29 → 9.04 | 215.98 → 0.88 |
| 32 | 14.28 → **9.36** | 336.07 → **1.50** |

plain 从 depth 2 到 32 终值从 7.62 涨到 9.36(**越深越差**);residual 反而从 4.34 降到 1.50 附近。这是一次完整的退化问题复现(非框架、纯 NumPy、可重跑)。

### 2. 为什么恒等短路有用:反向展开

对 `x_{l+1} = x_l + F(x_l)`,从第 L 层往回推:

```
∂ε/∂x_l = ∂ε/∂x_L · ∏_{i=l}^{L−1} ( 1 + ∂F(x_i)/∂x_i )
```

连乘里的 **`1`** 是恒等短路贡献的。哪怕每个 `∂F/∂x` 都很小(接近 0),连乘也不会塌成 0,因为每一项至少是 1;反过来,如果短路被替换成 `λ·x`(或任意线性投影 `W x`),那一项就变成 `λ` 或 `W`,连乘会按 `λ^L` 或 `‖W‖^L` 衰减。

初始化时的实测(depth=32、H=48、loss = ½‖h‖²、逐块 `‖∂L/∂W1‖`):

| 架构 | 第 1 块 | 第 16 块 | 第 32 块 | 首/末比 |
| --- | --- | --- | --- | --- |
| plain | 2.237e+03 | 1.065e+02 | 2.381e+01 | **93.94** |
| residual | 1.792e+02 | 6.292e+01 | 5.425e+01 | **3.30** |

plain 的输入侧梯度被压掉两个数量级(93.9×),residual 只压掉 3.3×,相差 **28.4 倍**。

### 3. 前向同样受益:信号不会被逐层吃掉

`‖x_l‖/‖x_0‖`(同一次初始化):

| 架构 | 第 1 块 | 第 16 块 | 第 32 块 |
| --- | --- | --- | --- |
| plain | 0.473 | 0.413 | 0.483(有界) |
| residual | 1.194 | 2.780 | **3.626**(随深度累积) |

residual 的信号沿恒等通道累积,深度不再意味着衰减。**代价**同样可见:残差流范数随深度增长,输出尺度也一起涨 —— 本目录里 residual 的初始损失是 336 而 plain 只有 14.3;把 lr 从 0.005 提到 0.01 时**只有 residual 发散**。这解释了真实网络里 residual 分支为什么几乎总配归一化(本 demo 为了公平对比,两种架构在每个单元分支入口都放了同一个逐样本归一化,否则无归一化的 residual 在 depth=32 时 `‖x_L‖/‖x_0‖` 会到 4.4e+02 且直接训崩)。

### 4. shortcut 消融

depth=32,3 个 seed 取中位数:

| shortcut | 表达式 | 首/末梯度 | 训练终损失 |
| --- | --- | --- | --- |
| identity | `x` | **3.110** | **1.5013** |
| scale | `0.9 x` | 1.237 | 3.5026 |
| proj | `0.9 · x[:, ::-1]`(无参 1×1 的替身) | 0.667 | 3.1581 |

结论与论文 Table 1 一致:**恒等**最好,任何"带缩放的短路"都会把输入侧梯度按 `λ^L` 压下去。这里 `scale`/`proj` 的首/末比都掉到 1.24/0.67(即靠近输出的梯度反而更大),与恒等的 3.11 形成清晰分层。

### 5. Pre-activation 与 Post-activation

```
Post-activation(原始版):  x_{l+1} = relu( BN(W2 relu(BN(W1 x_l))) + x_l )   # 相加后又过激活
Pre-activation (推荐):     x_{l+1} = x_l + W2 relu(BN(W1 · LN(x_l)))        # 相加后是纯恒等
```

区别在于"相加之后是否还有非线性"。只要相加后还有 ReLU/BN,`x_{l+1} = x_l + F(x_l)` 这个干净形式就被破坏,恒等通道不再是严格恒等,梯度直通性变差(论文用 1001 层 CIFAR-10 网络做了消融:pre-activation 更好训练)。本目录的 residual 就是 pre-activation 形式(归一化在分支入口),这也是现代 Transformer 的 Pre-LN 同源做法。

## 对比 / 选型

| 方案 | 梯度直通 | 参数量 | 相加后是否恒等 | 备注 |
| --- | --- | --- | --- | --- |
| 无短路(plain) | 无 | 相同 | — | 深了训不动 |
| `x + F(x)`(恒等) | 有(`1` 项) | 0 额外 | 是(pre-activation) | ResNet / Transformer 主流 |
| `λx + F(x)` | 部分(按 `λ^L`) | 0 额外 | 是 | 实测更差 |
| `Wx + F(x)`(1×1 投影) | 弱 | `H²` | 是 | 只在通道数变化处使用 |
| `g(x)·F(x)`(门控) | 视门控 | 额外 | 否 | 属 Highway 网络一脉 |

def forward(h, units, kind, shortcut="identity"):
    for W1, b1, W2, b2 in units:
        n, ln_cache = ln_forward(h)                 # 归一化放在**分支入口**(pre-activation)
        r = np.maximum(n @ W1 + b1, 0.0)
        f = r @ W2 + b2

    return h, caches

def backward(dh, units, caches, kind, shortcut="identity"):
    for i in reversed(range(len(units))):
        df = dh                                     # 分支梯度 = 上游梯度

## 性能与边界

- 恒等短路**不增加**参数与 FLOPs,只增加一次逐元素加法(与激活的带宽同量级)。
- 代价是**激活内存**:反向必须保存每个块的输入(或重算),深度大时这是显存主因。
- 残差流范数随深度增长(实测 depth 32 时 3.63×),所以深残差网络通常必须配合归一化与 warmup;不配时梯度与损失尺度都会漂。
- 本 demo 的规模(depth≤32、H=48、全批量 GD)只用于展示**方向性结论**,不能外推为收敛速率或精度预测。

## 注意事项与常见坑

1. **相加之后不要再加非线性**:`relu(F(x)+x)` 会让恒等通道失效(pre-activation 的动机)。
2. **短路不能用缩放/投影替代**:实测终损失 1.50 → 3.50 / 3.16,梯度剖面同时变差。
3. **维度不匹配时用 1×1 投影**:只在通道数变化处使用(`Wx + F(x)`),不要全局替换恒等。
4. **残差流会累积量级**:输出尺度随深度增长,学习率要按此下调(本目录 lr 0.01 时只有 residual 发散)。
5. **不配归一化的深残差网络会训崩**:实测无归一化时 depth=32 初始损失 2.9e+06。
6. **两个"1"不要混淆**:`∂ε/∂x_l` 展开式里的 `1` 是恒等短路带来的;而 plain 网络里没有它,连乘退化成 `∏∂F/∂x`,这就是梯度差 28 倍的来源。

## 参考资料(实际阅读过的权威来源)

- [Deep Residual Learning for Image Recognition (He et al. 2015, arXiv:1512.03385)](https://arxiv.org/abs/1512.03385) — 退化问题的定义("Deeper neural networks are more difficult to train",且与过拟合无关);残差学习显式重写为 `F(x) = H(x) − x`;152 层 ImageNet 取得 3.57% top-5 错误率;CIFAR-10 上 100/1000 层的分析。
